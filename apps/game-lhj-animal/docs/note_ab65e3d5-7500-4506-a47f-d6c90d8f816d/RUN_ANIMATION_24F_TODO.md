## 3. 동물별 프롬프트 변형 규칙

공통 24단계 발 순서는 유지하되 동물별로 아래 항목만 바꾼다.

- 체급: 착지 압축량, 체공 높이, 보폭 길이
- 꼬리: 몸보다 1~2프레임 늦게 따라오는 후행 동작
- 머리 특징: 뿔·긴 주둥이·큰 귀가 프레임 경계를 넘지 않게 고정
- 고유 소품: 달리기 중에도 위치·크기·색상 유지
- 성격: 느긋함·민첩함·저돌성 등 속도감에만 반영하고 발 순서는 변경하지 않음

### 3-1. 24포즈 수량 안정화 방식

- 한 장에 24포즈를 직접 요구하면 모델이 20~21포즈로 축약하는 사례가 반복되어 최종 방식에서 제외한다.
- 오른발 선행 반주기 12포즈와 왼발 선행 반주기 12포즈를 각각 정확한 `4열 × 3행` 시트로 생성한다.
- 두 반주기를 시간순으로 결합해 24프레임으로 만들고, 결합 경계인 12→13과 24→1의 얼굴·몸통·소품 연속성을 GIF로 별도 확인한다.
- 생성 시트의 그리드는 AI가 그리지 않으며, 각 4×3 셀을 독립적으로 분리한 뒤 공통 스케일·셔츠 중심 가로 앵커·최소 5px 여백을 적용한다.

## 4. 중복 검사 판정

- 완전 중복: `aHash hamming = 0` 및 `alpha MAD < 0.005` → 불합격
- 근접 중복: `aHash hamming <= 20` 및 `alpha MAD < 0.035` → 검토 목록
- 인접 프레임의 근접 유사성은 인비트윈으로 허용 가능
- 반주기 이상 떨어진 프레임의 근접 유사성은 중복 포즈 가능성이 높으므로 우선 교체
- 검사 결과는 각 동물 폴더의 `duplicate-report.txt`에 기록

## 4-1. 셀 독립성 검사

- 모든 프레임은 동일한 직사각형 셀 하나를 독립적으로 사용한다.
- 캐릭터·소품·안티에일리어싱을 포함한 alpha > 0 픽셀의 바운딩박스를 셀별로 계산한다.
- `left`, `top`, `right`, `bottom` 네 여백이 모두 최소 5px 이상이어야 한다.
- 마스터 시트에서는 가능하면 24px 안전 여백을 사용하고, 최종 리사이즈·패킹 후에도 5px 미만으로 줄이지 않는다.
- 주둥이 아래, 팔 사이, 꼬리 위처럼 비어 보이는 공간에 인접 프레임의 신체를 끼워 넣는 인터로킹 배치를 금지한다.
- 셀 경계를 가로지르는 연결요소, 이웃 캐릭터 조각, 고립된 알파 픽셀이 하나라도 발견되면 불합격이다.
- 검수 시 시트만 보지 말고 개별 셀 PNG를 실제로 잘라 확인한다.
