# 미니게임 디자인

## 1. 핵심 룰
**1 미니게임 = 1 동물 = 1 직업.** 각 동물의 실제 행동 특성을 미니게임 조작 메커닉으로 그대로 옮긴다. 단, 4장의 수달 콤비처럼 **1 미니게임 = 동물 2마리(협동 팀)**인 예외도 둔다.

---

## 2. 동물-직업-메커닉 매칭 표 — 원안
| 동물 | 직업 | 행동 특성 → 메커닉 |
|---|---|---|
| 악어 | 세탁소 사장 | 입을 벌려 태엽(스위치)을 물고, 데스롤(회전) 동작으로 세탁기를 돌림 |
| 새 | 우편배달부 | 신문·편지를 물고 하늘을 날아 배달 |

---

## 3. 확장 제안 — 동물-직업 매칭 후보
미니게임 라인업을 늘릴 때 참고할 수 있도록, 행동 특성이 메커닉으로 잘 치환되는 동물들을 추려보았다.

| 동물 | 직업 | 행동 특성 → 메커닉 |
|---|---|---|
| 비버 | 목공소 사장 | 이빨로 나무를 쏠아 다듬는 습성 → 목재 가공/건축 미니게임 |
| 다람쥐 | 창고·보관업 | 도토리를 저장하는 습성 → 물건을 종류별로 분류·적재하는 퍼즐 |
| 두더지 | 배관/지하철 정비공 | 땅굴을 파는 습성 → 터널 뚫기·배관 연결 미니게임 |
| 문어 | 식당 요리사 | 팔 8개 → 여러 조리기구를 동시에 조작하는 멀티태스킹 게임 |
| 캥거루 | 택배기사 | 배주머니에 짐을 담고 점프 이동 → 배달 경로/점프 액션 |
| 펠리컨 | 어시장 상인 | 큰 부리로 물건을 담아 나름 → 큰 부리로 물건을 받아내는 캐치 게임 |
| 여우 | 잡화점/정보상 | 영리하고 꾀 많은 이미지 → 손님과의 흥정·협상 미니게임 |
| 곰 | 양봉·꿀가게 | 발톱으로 벌집을 채취 → 벌 피하며 꿀 채집하는 리듬 게임 |
| 코알라 | 낮잠카페/휴게소 | 나무에 붙어 오래 자는 습성 → 손님 응대를 여유롭고 느린 템포로 진행 |

이 표는 확정안이 아니라 후보 풀이며, 실제 채택 시 코어 루프(조작 1~2개로 표현 가능한지)와 굿즈화 가능성을 기준으로 추리는 작업이 필요하다.

캐릭터 로스터·복장 등 시각적 디자인 방향은 **캐릭터 디자인** 페이지 참고.

---

## 4. 협동형 미니게임 — 수달 콤비 *(신규 제안)*
- 수달은 물살에 떠내려가지 않으려고 서로 손을 잡고 떠 있는 습성으로 유명하다. 이 습성을 그대로 **2인 1조 협동 미니게임**으로 옮긴다.
- **직업:** 온천/목욕탕 때밀이 콤비
- **메커닉 제안:** 두 플레이어(혹은 한 명이 두 마리를 동시에 조작)가 서로 "손을 놓치면 안 되는" 상태로 물 위 장애물을 피해 목욕용품을 나른다. 한쪽이 장애물에 부딪히면 둘 다 손이 풀려 물건을 떨어뜨리는 방식이라, 손발이 안 맞을수록 더 웃긴 그림이 나온다 — 샌드박스+챌린지 톤에 맞는 "완벽하지 않아도 재밌는" 협동 실패가 핵심.
- 다른 동물들의 협동 없는 솔로 미니게임과 구분되는 **유일한 2인 1조 캐릭터 케이스**. (캐릭터 디자인 페이지 3-4 참고)
- 이후 다른 동물에게도 협동 미니게임을 확장하고 싶다면, 반드시 "수달처럼 종 자체가 짝인 캐릭터"일 필요는 없다 — 서로 다른 동물 2마리가 우연히 한 팀이 되는 협동전(예: 캥거루+새의 배달 계주)도 가능하다.

## 5. 확장 제안 2 — 챌린지/샌드박스 특화 미니게임 *(신규 제안)*
> "조작이 쉽고, 생각할 게 별로 없고, 단순하고 직관적"이라는 기준과 "난장판이 나는 게 재밌는" 샌드박스+챌린지 톤에 맞춰 추가로 뽑아본 후보들. 폴가이즈·구스구스덕류의 파티게임 혼돈감을 참고했다.

| 동물 | 직업 | 조작 | 메커닉 & 난장판 포인트 |
|---|---|---|---|
| 염소 | 이삿짐센터 기사 | 버튼 1개(돌진) | 박치기로 상자를 밀어 옮기는 게 원래 임무인데, 여러 명이 동시에 밀다 보면 서로 들이받고 상자가 사방으로 튐 — 조작은 "돌진" 하나뿐 |
| 플라밍고 | 요가/발레 강사 | 좌우 기울이기 | 좁은 외발 발판 위에서 균형만 잡으면 되는데, 다른 플레이어와 부딪히면 휘청 — Fall Guys식 밸런스 탈락전 |
| 스컹크 | 청소업체 사장 | 버튼 1개(냄새 스프레이) | 자기 구역 청소하며 남의 시야/이동을 스프레이로 방해 — 파티게임 특유의 "훼방꾼" 포지션 |
| 앵무새 | 라디오 DJ/성대모사꾼 | 화면 지시 따라하기 | 사이먼 세즈 방식으로 나온 소리·동작을 그대로 따라하는 반응속도 게임, 규칙은 단순하지만 속도가 빨라질수록 다같이 우왕좌왕 |
| 코뿔소 | 철거반 인부 | 버튼 1개(차지) | 돌진으로 장애물을 부수며 전진, 다른 플레이어와 충돌하면 서로 밀려나는 데몰리션 더비 |
| 판다 | 분식집 사장 | 연타 | 제한시간 내 최대한 많이 먹는 단순 연타 대결, 규칙은 쉽지만 서로 먹을 걸 가로채는 몸싸움이 생김 |

이 표도 3장과 마찬가지로 후보 풀이며, 실제 채택 여부는 굿즈화 가능성·제작 난이도와 함께 검토 필요.

## 6. 미니게임 설계 원칙 *(신규 정리)*
샌드박스+챌린지 톤을 유지하기 위해, 앞으로 미니게임을 추가할 때 아래 기준을 함께 체크한다.
1. **조작은 1~2개 입력으로 설명 가능해야 한다** — 버튼 1개(돌진/스프레이 등), 방향 기울이기, 연타처럼 룰 설명 없이 바로 손이 가는 수준.
2. **생각보다 몸이 먼저 반응하는 게임이어야 한다** — 전략보다 타이밍·반사신경 위주.
3. **다인원 충돌/방해 요소를 적극적으로 넣는다** — 조용히 혼자 클리어하는 게임보다, 다른 플레이어와 부딪히거나 서로를 방해하며 "난장판"이 되는 그림을 우선한다.
4. **실패해도 웃긴 결과가 나와야 한다** — 4장 수달 콤비처럼, 완벽한 클리어보다 "삐끗해서 망하는" 순간 자체가 재미 포인트가 되도록 설계.

## 7. 추가로 정리가 필요해 보이는 항목 (AI 제안)
> 6장에서 설계 원칙은 정리됐다. 남은 항목은 아래와 같다.

1. **미니게임 공통 플로우** — 입장 → (튜토리얼) → 플레이 → 결과 → 보상으로 이어지는 공통 진행 구조가 아직 없다.
2. **난이도·제한시간·점수 시스템** — 미니게임별 난이도 곡선, 제한시간, 점수/성공판정 기준이 없다.
3. **실패 조건 및 재도전 방식** — 실패 시 패널티나 재도전 흐름(횟수 제한, 재화 소모 등)이 미정.
4. **출시 시점 미니게임 개수 및 우선순위** — 세계관 페이지에서도 언급된 항목으로, 후보가 15종 이상으로 늘어난 만큼 실제로 몇 개를 어떤 순서로 만들지 우선순위가 더 필요해졌다.
5. **보상 연결 구조** — 미니게임 완료 시 얻는 보상이 재화인지, 굿즈 포인트인지, 마을 꾸미기 아이템인지 등 게임 시스템과의 연결이 없다 → **게임 시스템** 페이지 참고.
