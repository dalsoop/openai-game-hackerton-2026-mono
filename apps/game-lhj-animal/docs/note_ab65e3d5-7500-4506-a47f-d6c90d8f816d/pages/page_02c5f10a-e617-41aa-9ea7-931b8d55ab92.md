# 캐릭터 디자인

## 1. 리더 캐릭터 — 카피바라

### 1-1. 왜 카피바라인가
1. **클리셰 탈피** — 보통 리더 역할은 사자·호랑이(강함) 혹은 코끼리(덩치)처럼 힘 있는 동물이 맡는다. 카피바라는 그 공식에서 벗어난다.
2. **'인싸' 밈** — 카피바라는 온천에 유자를 띄우고 다른 동물들과 잘 어울려 지내는 이미지로 이미 대중에게 "누구와도 잘 지내는 동물"로 각인되어 있다.
3. **대세감** — 최근 캐릭터 상품·이모티콘·게임 등에서 카피바라 단독 굿즈가 나올 정도로 수요가 높은 동물이다.

### 1-2. 리더십의 성격
- 힘이나 위계가 아니라 **친화력과 포용력**으로 리더가 된 캐릭터. "유비형 리더십"에 가깝다.
- 뽑기 기계라는 장치가 추구하는 정서(재미·놀이·다 같이 어울림)와 강함 중심의 리더보다 훨씬 잘 맞는다.

### 1-3. 직함 톤 — 결정 필요
"국회의원 / 시장 / 왕 / 리더 / 반장" 후보가 모두 나와 있는데, 이는 세계관의 전체 톤을 결정하는 요소라 하나로 좁힐 필요가 있다.
- **국회의원 / 시장** → 도시 시뮬레이션·풍자 코미디 톤 (주토피아에 가까운 성인 유머 여지)
- **왕** → 동화적·판타지 톤
- **반장 / 대장** → 아동·전연령 친화적, 마을 공동체 톤
- **제안:** 캡슐뽑기·귀여운 동물이라는 소재 자체가 전연령·귀여움 지향에 가깝다면 "반장" 또는 "촌장"류의 톤이 카피바라의 친화력 컨셉과 가장 잘 맞아떨어질 것으로 보인다. "국회로!"라는 원안의 언어유희를 살리고 싶다면 시장 선거 같은 가벼운 이벤트성 서브플롯으로 다루는 절충안도 가능.

## 2. 플레이어 캐릭터 컨셉
유저가 동물에 빙의/변장하는 세계관상의 진입 동기는 **세계관** 페이지 2장 참고. 빙의 vs 변장 여부는 플레이어 캐릭터를 별도로 그릴지, 동물 캐릭터가 곧 플레이어인지를 가르는 문제라 이 페이지의 캐릭터 디자인 범위에도 직결된다 — 결정 필요.

## 3. 등장 동물 캐릭터 로스터

### 3-1. 핵심 룰
**1 미니게임 = 1 동물 = 1 직업.** 각 동물의 실제 행동 특성을 미니게임 조작 메커닉으로 그대로 옮긴다. 단, 3-4의 협동형처럼 **1 미니게임 = 동물 2마리(한 팀)**인 예외도 둘 수 있다. (메커닉 상세는 **미니게임 디자인** 페이지 참고)

### 3-2. 원안 예시
| 동물 | 직업 | 행동 특성 → 메커닉 |
|---|---|---|
| 악어 | 세탁소 사장 | 입을 벌려 태엽(스위치)을 물고, 데스롤(회전) 동작으로 세탁기를 돌림 |
| 새 | 우편배달부 | 신문·편지를 물고 하늘을 날아 배달 |

### 3-3. 확장 제안 — 동물-직업 매칭 후보
미니게임 라인업을 늘릴 때 참고할 수 있도록, 행동 특성이 메커닉으로 잘 치환되는 동물들을 추려보았다.

| 동물 | 직업 | 행동 특성 → 메커닉 |
|---|---|---|
| 비버 | 목공소 사장 | 이빨로 나무를 쏠아 다듬는 습성 → 목재 가공/건축 미니게임 |
| 다람쥐 | 창고·보관업 | 도토리를 저장하는 습성 → 물건을 종류별로 분류·적재하는 퍼즐 |
| 두더지 | 배관/지하철 정비공 | 땅굴을 파는 습성 → 터널 뚫기·배관 연결 미니게임 |
| 문어 | 식당 요리사 | 팔 8개 → 여러 조리기구를 동시에 조작하는 멀티태스킹 게임 |
| 캥거루 | 택배기사 | 배주머니에 짐을 담고 점프 이동 → 배달 경로/점프 액션 |
| 펠리컨 | 어시장 상인 | 큰 부리로 물건을 담아 나름 → 큰 부리로 물건을 받아내는 캐치 게임 |
| 여우 | 잡화점/정보상 | 영리하고 꾀 많은 이미지 → 손님과의 흥정·협상 미니게임 |
| 곰 | 양봉·꿀가게 | 발톱으로 벌집을 채취 → 벌 피하며 꿀 채집하는 리듬 게임 |
| 코알라 | 낮잠카페/휴게소 | 나무에 붙어 오래 자는 습성 → 손님 응대를 여유롭고 느린 템포로 진행 |

이 표는 확정안이 아니라 후보 풀이며, 실제 채택 시 코어 루프(조작 1~2개로 표현 가능한지)와 굿즈화 가능성을 기준으로 추리는 작업이 필요하다.

### 3-4. 협동형(2인 1조) 캐릭터 — 수달 콤비
- **수달**은 실제로 잠들 때 물살에 떠내려가지 않으려고 서로 손을 잡고 떠 있는 습성으로 유명하다("손잡고 자는 수달" 밈). 이 습성을 그대로 캐릭터 컨셉에 반영해, **처음부터 2마리가 한 세트인 캐릭터**로 제안한다.
- 직업 제안: **온천/목욕탕 때밀이 콤비** — 항상 붙어다니며 함께 일하는 컨셉이 목욕탕 업무와도 잘 어울린다.
- 다른 동물들이 "1미니게임 = 1동물"인 것과 달리, 수달은 "1미니게임 = 수달 2마리(협동)"가 되는 유일한 예외 케이스 — 로스터에서도 시각적으로 항상 붙어있는 듀오로 표기.
- 협동 미니게임 메커닉 상세는 **미니게임 디자인** 페이지 4장 참고.

## 4. 동물 성격 & 관계도
> 습성으로 미니게임 메커닉을 뽑아냈던 것처럼, 성격도 같은 방식으로 잡아봤다. 대사 톤·연출 참고용 초안이며 실제 시나리오 작업 시 다듬을 것.

### 4-1. 성격 프로필
| 동물 | 직업 | 성격 한 줄 | 말투 톤 |
|---|---|---|---|
| 카피바라 | 마을 리더 | 누구와도 잘 지내는 포용형 리더 | 느긋하고 다정한 존댓말 |
| 악어 | 세탁소 사장 | 무뚝뚝해 보여도 뒤끝 없는 화끈한 사장님 | 걸걸하고 시원시원함 |
| 새 | 우편배달부 | 부지런하고 참견 많은 마을 소문통 | 빠르고 수다스러움 |
| 비버 | 목공소 사장 | 뭐든 뚝딱 고치는 과묵한 장인 | 말수 적고 단답형 |
| 다람쥐 | 창고업 | 잃어버릴까 늘 안절부절하는 걱정형 | 조급하고 소심함 |
| 두더지 | 배관 정비공 | 낯가림 심한 은둔형, 땅속이 제일 편함 | 웅얼웅얼 소극적 |
| 문어 | 식당 요리사 | 정신없이 바쁜 자신만만한 멀티태스커 | 오지랖 넓고 빠름 |
| 캥거루 | 택배기사 | 승부욕 강한 성격 급한 스피드광 | 활기차고 거침없음 |
| 펠리컨 | 어시장 상인 | 능글맞고 넉살 좋은 허풍쟁이 장사꾼 | 구수하고 넉살 좋음 |
| 여우 | 잡화점/정보상 | 계산 빠르고 얄미울 만큼 영리한 협상가 | 능청스럽고 여유로움 |
| 곰 | 양봉·꿀가게 | 느긋하고 다정한 큰형님/큰누나 | 낮고 푸근함 |
| 코알라 | 낮잠카페 | 만사 귀찮은 나른한 힐러형 | 늘어지는 반말투 |
| 수달 콤비 | 목욕탕 콤비 | 늘 붙어다니는 장난기 많은 절친 듀오 | 서로 말 주고받듯 맞장구 |

### 4-2. 관계도
| 동물 | 친한 사이 | 살짝 먼 사이 | 비고 |
|---|---|---|---|
| 카피바라 | 전원 | 없음 | 마을 허브 캐릭터, 모두와 두루 친함 |
| 수달 콤비 | 서로(당연), 펠리컨 | — | 물가에서 자주 마주쳐 펠리컨과 친함 |

| 비버 | 두더지 | — | 나무 다듬는 비버 + 땅 파는 두더지, 마을 인프라 콤비 |

| 새 | 앵무새 | 캥거루 | 둘 다 날개 달린 동물이라 마을 소문을 함께 나름 |
| 곰 | 코알라 | — | 둘 다 여유로운 성격이라 죽이 잘 맞음, 곰이 카페에 꿀을 납품 |
| 코알라 | 곰 | — | 위와 동일 |

> 관계 설계 기준: (1) 카피바라를 관계망의 중심 허브로 둬서 "누구와도 잘 지낸다"는 컨셉을 구조적으로 뒷받침, (2) 실제 동물 생태(포식자-피식자, 서식지 인접)를 코믹한 긴장 요소로 살짝만 사용, (3) 완전한 적대 관계는 두지 않고 "살짝 먼 사이" 수준의 가벼운 라이벌/거리감으로만 표현 — 전연령 톤 유지.

## 5. 아트 스타일 — 캐릭터 실루엣

### 5-1. 이 계열은 보통 뭐라고 부르나
- **플랫 벡터 아트(Flat Vector Art) / 캐주얼 플랫 일러스트** — 그림자·그라데이션을 최소화하고 단순한 도형과 단색 위주로 캐릭터를 구성하는 스타일을 업계에서 부르는 일반적인 명칭.
- 캐릭터 형태 자체는 흔히 **"빈(Bean) 캐릭터" / "젤리빈 캐릭터"**라는 별칭으로 불린다 — 관절이나 근육 표현 없이 알약·캡슐형 몸통 하나로 이루어지고, 실루엣만으로 종을 구분하는 방식.
- 크게 보면 **SD(Super Deformed)/치비류**의 단순화된 캐주얼 캐릭터 디자인의 한 갈래이지만, 치비가 "큰 머리 + 작은 몸"에 초점을 둔다면 어몽어스류는 머리와 몸을 구분하지 않는 **하나의 덩어리(캡슐형) 실루엣**이라는 점이 다르다.

### 5-2. 우리 세계관과의 접점
- **제안:** 캐릭터 몸통을 "캡슐형 실루엣"으로 통일하면, 캡슐뽑기 기계라는 세계관 상징과 아트 스타일이 정확히 맞아떨어진다. 캡슐에서 나온 존재라는 설정과 캡슐형 바디가 시각적으로도 연결되는 셈.
- 각 동물은 귀·꼬리·색상·무늬 등 최소한의 특징 요소만으로 구분하면 되므로, 복잡한 근육·관절 표현 없이도 다품종(동물별 직업 캐릭터) 제작이 효율적이다.
- 직업별 복장·장신구는 캡슐형 몸통 위에 얹는 심플한 아이템으로 표현하는 편이 톤에 맞는다 — 상세는 **의상 디자인** 페이지 참고.

### 5-3. 동작 원칙 — 이족보행 / SD 비율 / 셀애니메이션
- **이족보행:** 모든 동물이 네발이 아니라 **사람처럼 서서 두 발로 걷는** 형태로 통일한다. 어몽어스·구스구스덕과 동일한 원칙으로, 의상을 입히기도 쉽고 조작감(정면/측면 스프라이트 전환)도 단순해진다.
- **SD 비율:** 머리·몸통 구분이 없는 캡슐형 실루엣에 **1.5~3등신 범위** 내에서 동물별로 유동적으로 SD 비율을 적용한다 — 다람쥐·수달처럼 작고 아기자기한 동물은 1.5등신에 가깝게, 코뿔소·곰처럼 덩치가 큰 동물은 3등신에 가깝게 잡는 식으로 종별 체급감을 살릴 수 있다.
- **셀 애니메이션 원칙:** 그라데이션 없이 **면을 딱 나눈 셀 음영**(하이라이트/베이스/그림자 1단씩만)으로 채색한다. 세부 규칙은 6장 컬러 예산 참고.
- **통통 튀는 애니메이션:** SD 비율의 통통한 몸에 맞춰, 이동 모션에 **스쿼시&스트레치(눌렸다 늘어나는) 바운스감**을 기본값으로 준다 — 예를 들어 뛸 때 몸통이 위아래로 살짝 눌렸다 펴지는 식. 어몽어스처럼 좌우 반전(플립)만으로 방향을 표현하는 미니멀 스프라이트 원칙과도 잘 맞는다. 서서 뛰어다니는 느낌을 기본으로 하며, 실제 애니메이션 목록은 **애니메이션 디자인** 페이지, 대기 시 재생되는 파티클은 **파티클 디자인** 페이지 참고.

### 5-4. 자료 조사용 키워드 정리
레퍼런스 조사나 아트 외주 발주 시 아래 키워드로 검색하면 유사 사례를 찾기 좋다.
- Flat Vector Character Art / Casual Mobile Game Art
- Bean-shaped Character Design / Jellybean Character
- Top-down 2D Multiplayer Game Art
- Minimal Silhouette Character Design
- Squash and Stretch SD Character Animation

## 6. 캐릭터 컬러 예산 — 5~6색 규칙
그라데이션 없는 셀 애니메이션 스타일을 유지하면서 제작 효율을 높이기 위해, **캐릭터 한 마리가 화면에 보일 때 동시에 쓰이는 색을 5~6가지로 제한**한다. "동물 고유색"과 "1P~15P 의상색"이 이 예산 안에서 함께 굴러가는 구조다.

| # | 슬롯 | 성격 | 비고 |
|---|---|---|---|
| 1 | 아웃라인 | 전 캐릭터 공통 고정 (#202024 계열) | 모든 캐릭터·의상 공통 |
| 2 | 동물 베이스 컬러 | **동물마다 다른 고유색** | 종을 구분하는 가장 넓은 면적의 색 (예: 곰=갈색, 여우=주황) |
| 3 | 동물 쉐이드 컬러 | 베이스에서 자동 파생 | 베이스보다 명도 -15% 정도 어둡게, 그라데이션 대신 경계가 뚜렷한 셀 그림자 1단 |
| 4 | 동물 포인트 컬러 | 대부분 공통 (아이보리/화이트 계열) | 배·볼·귀 안쪽 등 2차 특징 부위 |
| 5 | 의상색 | **플레이어마다 다른 색 (1P~15P 중 택1)** | 실제 구현 방식(셰이더 컬러 스와핑)과 팔레트는 **의상 디자인** 페이지 참고 |
| 6 | 하이라이트 화이트 | 전 캐릭터 공통 고정 | 눈동자 하이라이트·이빨 등 |

즉, 새 동물을 하나 추가할 때 디자이너가 실제로 새로 고민해야 하는 색은 **"2번 베이스 컬러" 단 1개**뿐이고(3번 쉐이드는 자동 파생, 1·4·6번은 공통 고정), 플레이어 구분은 5번 의상색이 전담한다.

## 8. 추가로 정리가 필요해 보이는 항목 (AI 제안)
> 애니메이션·파티클 관련 세부 내용은 **애니메이션 디자인**, **파티클 디자인** 페이지로 분리했다.

1. **캐릭터 고유 이름** — 지금은 "카피바라", "악어", "새"처럼 종(species) 이름이 곧 캐릭터명이다. 상품화(굿즈)·스토리 연출을 생각하면 종과 별개로 고유 이름을 붙일지 결정이 필요하다.
2. **레퍼런스 이미지 저작권 문제** — 지금 카피바라 각주 이미지는 namu.wiki 외부 저작물을 참고용으로 걸어둔 상태다. 실제 제작 단계에서는 반드시 자체 컨셉아트로 교체해야 한다.
3. **캐릭터 수 확장 로드맵** — 출시 시점에 몇 종으로 시작해서, 이후 업데이트마다 몇 종씩 추가할지에 대한 로드맵이 없다.
4. **동물 베이스 컬러 실제 배정표** — 6장에서 "동물마다 다른 고유색 1개"라는 규칙은 정했지만, 실제로 어떤 동물에게 어떤 색을 배정할지(예: 곰=브라운 계열, 여우=오렌지 계열)는 아직 표로 정리되지 않았다. 마젠타/핫핑크 계열은 **의상 디자인** 페이지의 셰이더 마스킹 색과 겹치므로 피해야 한다.
