# 게임 시스템

> 이 페이지는 기존 세계관 기획서에 없던, 게임 기획서라면 보통 필요한 시스템 항목들을 정리하기 위해 새로 추가한 페이지다. 아래 내용은 전부 미정 상태이며, 팀 논의를 거쳐 채워나가야 한다.

## 1. 장르 / 플랫폼
- **장르 확정: 샌드박스 + 챌린지.** 폴가이즈·구스구스덕류의 파티게임에 가까운 "조작은 단순하지만 다인원이 뒤엉켜 난장판이 되는" 톤으로 방향을 잡았다. 미니게임 설계 원칙은 **미니게임 디자인** 페이지 6장 참고.
- 플랫폼(모바일/PC/콘솔)과 세로/가로 화면 방향은 아직 명시된 바 없다 — 다만 캡슐뽑기 + 미니게임 옴니버스 구조로 보아 모바일 캐주얼 쪽에 가까워 보인다.

## 2. 코어 루프 (제안 초안)
확정된 코어 루프가 없어 세계관·미니게임 설정을 바탕으로 초안만 제시한다. 검토 후 수정 필요.
1. 로비(마을)에서 캡슐뽑기 기계로 이동
2. 캡슐(=미니게임)을 뽑아 진입 — 솔로 미니게임일 수도, 협동 미니게임(수달 콤비 등)일 수도 있음
3. 해당 동물의 직업 미니게임 플레이 — 단순 조작 + 다인원 충돌로 난장판이 되는 것을 전제로 설계
4. 결과에 따라 재화/보상 획득
5. 보상으로 새 캡슐을 뽑거나 마을·캐릭터를 꾸미고, 1번으로 순환

## 3. 수집 / 진행 시스템
- 동물 캐릭터를 순차적으로 "고용"하거나 "수집"하는 개념이 있는지, 아니면 처음부터 전체 동물이 열려 있는지 미정.
- 마을이 성장하는 요소(신규 상점 오픈, 마을 꾸미기 등)가 있는지 미정.
- **캐릭터 디자인** 페이지 4장에서 동물 간 친밀도/관계도를 정리했다 — 이 관계도를 실제 시스템(예: 친한 동물끼리 협동 미니게임 매칭, 관계도에 따른 마을 이벤트)에 연결할지는 미정.

## 4. 수익 모델
- 실물 굿즈 연계 아이디어는 세계관·캐릭터 페이지에 언급돼 있으나, 게임 내 수익모델(광고, 인앱결제, 캡슐 뽑기 확률형 아이템 여부 등)은 정해진 바 없다. 확률형 아이템을 쓸 경우 국내 확률 공시 규제 대상이 될 수 있어 조기에 방향을 정하는 게 좋다.

## 5. UI/UX 플로우
- 로비(마을 화면) → 캡슐머신 화면 → 미니게임 화면 → 결과 화면 간 전환 구조 미정.

## 6. 사운드 / 음악 방향
- 미정. 아트 방향(플랫 벡터, 귀여운 톤)에 맞는 BGM/SFX 톤 정의 필요.

## 7. 튜토리얼 설계
- **세계관** 페이지의 "진입 동기(훅)"이 정해지면, 그 훅을 그대로 오프닝 튜토리얼 연출로 연결할 수 있다. 아직 구체적인 튜토리얼 단계 설계는 없음.

## 8. 타겟층
- "전연령·귀여움 지향" 톤이라는 언급은 있지만(**세계관** 페이지), 정확한 타겟 연령대·시장(국내/글로벌)은 미정.
