# 의상 디자인

## 1. 복장 규칙
- 세탁소처럼 노동을 하는 이상 동물들은 각자 직업에 맞는 옷(유니폼, 앞치마 등)을 입어야 한다는 설정이 이미 있음.
- **제안:** 이 복장은 단순 설정을 넘어 캐릭터의 직업 아이덴티티를 시각적으로 보여주는 장치이자, 추후 캡슐 피규어·굿즈 라인업(같은 동물의 직업별 다른 의상 변형)으로 확장하기 좋은 지점이다.
- 간단하게 곰돌이 푸, 징징이 등 같은 캐릭터처럼 윗옷(반팔 티셔츠)만 입는 방식으로 확정 — 아래 2~4장에서 이 결정을 실제 구현/팔레트/착용품 구성으로 구체화한다.

---

## 2. 구현 방식 — 셰이더 컬러 스와핑 (마젠타 마스킹) *(신규 확정 사항)*
플레이어별 의상색(1P~15P)을 표현할 때, **의상마다 색을 다 따로 그리지 않고 셰이더로 색만 바꿔치기**하는 방식으로 진행한다.

- **원리:** 의상 스프라이트에서 플레이어별로 바뀌어야 하는 영역(반팔티 몸판 등)만 마젠타(#FF00FF류의 눈에 띄는 고유색)로 칠해 넣는다. 런타임에 셰이더가 그 마젠타 픽셀을 감지해 해당 플레이어에게 배정된 색(3장 팔레트 중 1개)으로 치환한다. Among Us류가 흔히 쓰는 "컬러 키 마스킹" 기법과 동일한 방식이다.
- **의상색 외 나머지는 고정:** 마스킹 대상은 의상의 "플레이어 색을 나타내는 부분"뿐이고, 그 외 의상 디테일(단추, 주머니, 무늬 등)이나 4장의 개별 아이템은 색을 그대로 유지한다 — 원문 그대로 "그 외에 의상색은 그대로 유지되는 것".
- **장점:** 아트 리소스를 플레이어 수(최대 15명)만큼 각각 그릴 필요가 없다. 동물+의상 조합마다 마스크 포함 스프라이트 1장만 그리면 되므로, 동물 종류가 늘어나도 의상 색상 자산은 늘지 않는다.
- **유의점:** 마스킹 색(마젠타)과 동물 자체의 몸 색이 겹치면 셰이더가 캐릭터 몸까지 잘못 치환해버릴 수 있다. **캐릭터 디자인** 페이지 6장의 "동물 베이스 컬러"는 마젠타/핫핑크 계열을 피해서 배정해야 한다.
- **적용 범위:** 마젠타 마스킹은 1장의 의상(반팔티/앞치마 등 "옷")에만 적용한다. 4장의 모자·안경 같은 장신구는 원칙적으로 이 마스킹 대상이 아니라 고정색을 쓴다 — 플레이어 구분은 옷 색 하나로 충분하고, 장신구까지 색이 바뀌면 오히려 5-6색 예산을 넘어서서 산만해진다.

## 3. 의상색 팔레트 — 1P~15P

### 3-1. 설계 기준
- **채도 40~65%, 명도 38~60%** 범위로 통일 — 원색(100% 채도)처럼 쨍하게 눈부시지 않으면서도, 무채색에 가깝게 흐려서 배경에 묻히지도 않는 중간 지점.
- 색상(Hue)뿐 아니라 **명도·채도 차이도 함께 벌려서** 배치 — 색맹(적록색약 등)에게도 색상 차이만으로 구분이 안 될 경우를 대비해, 밝기 차이로도 구분되도록 함 (예: 그린/민트/시안은 색상은 가깝지만 명도를 단계적으로 다르게 잡음).
- **모든 캐릭터에 짙은 아웃라인(예: #202024 계열)을 공통으로 두르는 것을 전제**로 설계했다. 이 스타일 게임들(어몽어스 등)이 배경색과 무관하게 실루엣이 살도록 캐릭터에 진한 테두리를 쓰는 것과 같은 이유 — 배경이 밝든 어둡든 테두리가 1차 분리선 역할을 해준다.
- 15번(아이보리)만 예외적으로 밝은 값을 썼다. "화이트" 포지션이 필요해서 넣었는데, 순백(#FFFFFF)은 밝은 배경에 묻히므로 채도를 낮춘 아이보리 톤 + 아웃라인 조합으로 대체했다.

### 3-3. 주의할 점
- 그린(5P)·민트(6P)·시안(7P)과 옐로우(3P)·라임(4P)은 색상이 서로 가까운 축이라, 색약 사용자에게는 다른 색보다 구분이 어려울 수 있다. 지금은 명도 차이로 어느 정도 분리해뒀지만, 실제 제작 단계에서 Color Oracle 같은 색맹 시뮬레이터로 한 번 더 검증하는 것을 권장한다.
- 배경 톤이 확정되면(예: 파스텔 마을 배경 등) 그 배경과 겹치는 색이 없는지 재점검이 필요하다 — 지금은 "배경 미정" 상태를 가정해 중간값 위주로 잡은 팔레트다.
- 11P 핑크(#D9679E)는 2장의 마젠타 마스킹 색(#FF00FF류)과 색상 축이 가까운 편이다. 실제로는 채도·명도가 크게 달라 셰이더가 혼동할 일은 적지만, 마스킹 색을 고를 때는 11P와 최대한 멀리 떨어진 고채도 값을 쓰는 것이 안전하다.
- 동물 베이스 컬러(**캐릭터 디자인** 페이지 6장)도 이 15색 축과 채도·명도대가 어긋나지 않게 잡아야 의상색과 겹쳐 입어도 화면이 정신없어지지 않는다.

## 4. 착용품 구성 — 공용 vs 개별

전체 색 예산(캐릭터 디자인 페이지 6장)을 넘지 않으려면 장신구 자체의 종류를 늘리기보다, **"공용으로 재사용되는 소품"**과 **"그 동물이 아니면 의미가 없는 개별 소품"**을 나눠서 관리하는 편이 효율적이다. 이족보행 SD 캡슐 실루엣이라 몸 형태가 다 비슷하기 때문에, 종에 상관없이 걸칠 수 있는 부위(몸통, 목)와 특정 종의 신체 특징(부리, 볼주머니, 뿔, 주머니 등)에 얹는 부위를 구분하기 쉽다.

### 4-1. 공용 착용품 제안 (최대 3개)
| # | 아이템 | 왜 공용으로 제안하는가 |
|---|---|---|
| 1 | 민무늬 반팔 티셔츠 (반티) | 이미 결정된 기본안. 캡슐형 몸통의 가장 넓은 면(몸통)을 덮는 아이템이라 동물마다 체형이 달라도 실루엣이 거의 동일하게 나온다 — 2장 마젠타 마스킹을 얹는 기본 캐리어로 가장 적합. |
| 2 | 앞치마 (에이프런) | 원문 복장 규칙에도 이미 언급된 아이템으로, 요리사·세탁소·카페 등 여러 직업에 두루 어울린다. 앞판 하나로 이루어진 단순한 실루엣이라 종에 상관없이 몸통 앞에 걸치기만 하면 되고, 반팔티 대신 쓸 수 있는 대체 마스킹 캐리어로도 활용 가능. |
| 3 | 목에 두르는 스카프/반다나 | 목 부위는 어느 동물이나 캡슐형 몸통과 머리가 만나는 지점이라 형태가 균일하다. 특히 탑다운(위에서 내려다보는) 카메라 시점(**배경 디자인** 페이지 참고)에서는 몸통 색이 시야각에 가려 잘 안 보일 때가 있는데, 목에 두른 스카프는 위에서도 잘 읽혀서 플레이어 색 보조 표시로도 유용하다. |

### 4-2. 동물별 개별 아이덴티티 아이템 제안
공용 아이템과 달리, 아래 소품들은 **그 동물의 신체 특징이나 습성이 있어야만 성립**해서 다른 동물이 착용하면 의미가 없어지거나 어색해지는 것들이다. 착용 슬롯은 동물당 1개로 제한한다(5-6색 예산 유지 목적).

| 동물 | 개별 아이템 | 개별로 제안하는 이유 |
|---|---|---|
| 카피바라 | 촌장 메달/목걸이 | 리더라는 서사적 지위를 나타내는 상징물이라 다른 동물이 걸치면 "얘가 리더인가?" 하는 혼선을 준다 |
| 악어 | 이빨에 낀 태엽 손잡이 | "입으로 태엽을 물고 돌린다"는 이 캐릭터만의 미니게임 메커닉을 그대로 시각화한 소품 |
| 새 | 부리에 문 우편 가방 | 배달부라는 직업 실루엣을 결정짓는 핵심 소품, 다른 동물이 들면 새의 직업처럼 보여 혼동됨 |
| 비버 | 연필 꽂힌 목수 벨트 | 이빨로 나무를 다듬는 종 특유의 습성과 직접 연결된 작업 도구 |
| 다람쥐 | 볼주머니에 문 도토리 | 다람쥐만의 신체 기관(치크파우치)을 활용한 소품이라 이식 자체가 불가능 |
| 두더지 | 이마에 쓴 헤드랜턴 | "땅속" 서식 습성과 어두운 공간 작업이라는 직업 특성의 결합 |
| 문어 | 여러 팔에 쥔 조리도구 세트 | 팔 8개라는 신체 구조 자체가 개그 포인트라 다른 동물은 애초에 착용이 불가능 |
| 캥거루 | 배주머니 속 택배 상자 | 캥거루 고유 신체 기관(주머니)을 활용, 다른 동물은 주머니가 없음 |
| 펠리컨 | 부리 주머니 속 생선 | 부리 주머니라는 신체 특징이 어시장 직업과 완전히 결합 |
| 여우 | 외눈 안경(모노클) | "영리하고 계산 빠른 협상가"라는 성격을 상징, 이 캐릭터의 개성 서사와 강하게 묶임 |
| 곰 | 얼굴에 쓴 양봉 방충망 모자 | 벌을 다루는 직업 안전장비라 다른 직업 동물에겐 맥락이 없음 |
| 코알라 | 목에 두른 베개/쿠션 | "나른하게 늘어져 있다"는 성격을 시각화한 소품, 활동적인 동물에겐 안 어울림 |
| 수달 콤비 | 둘을 잇는 리본/끈 | 2인 1조라는 캐릭터 구조 자체를 나타내는 장치 — 혼자인 다른 동물에겐 아예 의미가 성립하지 않음 |

> 3-3에서 다룬 확장 후보(염소·플라밍고·스컹크·앵무새·코뿔소·판다 등)도 같은 방식으로 뿔 보호대, 외발 발찌 같은 습성 기반 개별 아이템을 붙이면 된다 — 실제 채택되는 시점에 표를 확장.

## 5. 추가로 정리가 필요해 보이는 항목 (AI 제안)
1. **마스킹 색상 확정** — 2장에서 "마젠타류"라고만 정했지, 실제 헥스값(#FF00FF 등)과 셰이더 허용 오차(안티에일리어싱 경계 처리) 규칙은 아직 없다.
2. **개별 아이템 색 처리 기준** — 4-2의 개별 아이템들도 셀 음영을 적용할지, 몇 색까지 허용할지(캐릭터 디자인 페이지 6장의 5~6색 예산 안에 포함되는지 별도 예산인지)가 명확하지 않다.
3. **굿즈화 시 마스킹 방식의 한계** — 실물 피규어·굿즈로 만들 때는 셰이더 마스킹을 쓸 수 없으니, 굿즈 라인업(1장 참고)은 결국 대표 색상 몇 가지를 실물용으로 별도 확정해야 한다.
