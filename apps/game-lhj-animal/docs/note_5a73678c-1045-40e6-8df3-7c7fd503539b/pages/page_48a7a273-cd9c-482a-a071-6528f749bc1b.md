# 총기 이펙트 시안

## 1. 문서 목적 및 범위
**총기 도트 시안** 문서의 12종 총기가 발사될 때 나오는 이펙트(총구화염·탄피·탄도·피격·화면 흔들림)를 **대/중/소 3단계**로 표준화해서 정의한다.

- **핵심 원칙:** 12종 총기마다 이펙트를 따로 그리지 않는다. **대/중/소 3세트의 이펙트만 제작**하고, 각 총기를 그중 하나에 배정해서 재사용한다 — 이 노트의 다른 문서들(부양 장치=공격 소품 겸용, 공용 애니메이션 재사용 등)과 동일한 "제작량을 줄이는" 원칙.
- **팔다리 없는 도트 캐릭터 시안** 6장의 "도구 분리 원칙"을 그대로 계승 — 이펙트도 캐릭터 원본 이미지에 합성하지 않고 독립 스프라이트/파티클 노드로 관리한다.

---

## 2. 이펙트 공통 구성 요소
모든 총기가 발사 시 아래 요소들의 조합으로 이펙트를 표현한다. 총기마다 있고 없고가 갈리는 요소도 있다(예: 유탄발사기는 탄피가 없고 착탄 폭발이 있음).

| 요소 | 설명 |
|---|---|
| 총구화염 (Muzzle Flash) | 격발 순간 총구에서 발생하는 섬광 |
| 탄도/예광선 (Tracer) | 총구에서 목표까지 이어지는 궤적선 |
| 탄피 배출 (Shell Eject) | 격발 후 튀어나오는 탄피 |
| 피격 이펙트 (Impact) | 탄이 명중했을 때 발생하는 스파크·파편 |
| 화면 흔들림 (Screen Shake) | 격발 반동의 무게감을 화면 전체로 전달하는 카메라 연출 |

## 3. 실제 이미지 생성 대상 — 3종 × 등급 3종 = 9장

2장 구성 요소 중 **실제로 이미지를 뽑는 대상은 아래 3종으로 좁힌다.**

1. **머즐 플래시 (Muzzle Flash)** — 총구 섬광
2. **총알 (Bullet / Tracer)** — 발사된 탄이 날아가는 궤적 스프라이트
3. **임팩트 (Impact)** — 명중 시 스파크·파편

탄피 배출과 화면 흔들림은 이번 생성 배치에서 제외한다 — 화면 흔들림은 이미지가 아니라 카메라 코드 연출이라 애초에 스프라이트가 필요 없고, 탄피는 우선순위를 낮춰 필요 시 별도 배치로 진행한다.

3종 × 대/중/소 등급을 조합하면 **총 9장이 이번 제작 배치의 전체 산출물**이다. 12종 총기는 5장 배정표에 따라 이 9장 중 해당 등급의 3장(머즐 플래시+총알+임팩트)을 그대로 가져다 쓴다 — 총기마다 새로 그리지 않는다는 1장 핵심 원칙이 실제로 여기서 "9장"이라는 구체적 숫자로 확정된다.

**형식 결정** — 셋 다 같은 형식으로 뽑지 않는다.
- **머즐 플래시 / 임팩트:** 프레임이 여러 장(1~4프레임)이라 등급당 **프레임 스트립(스프라이트 시트) 1장**으로 뽑는다.
- **총알:** 방향·실제 이동 경로는 코드(회전·포지션 트윈)로 처리하되, 무기 체감 차이를 위해 **경량탄·표준 소총탄·중량/저격탄·산탄 펠릿 4개 아키타입**을 둔다. 각 아키타입은 점형·짧은 잔상·중간 잔상·긴 잔상 4단계 중 하나를 정지 이미지로 선택하거나, 왼쪽에서 오른쪽으로 재생해 잔상이 길어지는 간단한 시각 애니메이션으로 사용할 수 있다.

| # | 이미지 | 등급 | 형식 | 규격 요약(4장 표 참고) |
|---|---|---|---|---|
| 1 | 머즐 플래시 | 소형 | 프레임 스트립(1~2프레임) | 반경 20~30px |
| 2 | 머즐 플래시 | 중형 | 프레임 스트립(2~3프레임) | 반경 40~50px |
| 3 | 머즐 플래시 | 대형 | 프레임 스트립(3~4프레임) | 반경 70~90px |
| 4 | 총알 | 소형 | 정지 이미지 1장 | 1px 직선형, 길이 40~60px |
| 5 | 총알 | 중형 | 정지 이미지 1장 | 2px 예광선형, 길이 80~120px |
| 6 | 총알 | 대형 | 정지 이미지 1장 | 굵고 존재감 있는 기본형 1종, 방향·부채꼴·포물선은 코드가 처리 |
| 7 | 임팩트 | 소형 | 프레임 스트립(1~2프레임) | 반경 ~15px, 점 스파크 |
| 8 | 임팩트 | 중형 | 프레임 스트립(2~3프레임) | 반경 ~25px, 스파크+파편 2~3개 |
| 9 | 임팩트 | 대형 | 프레임 스트립(3~4프레임) | 반경 ~40~60px, 스파크 폭발+파편 4~5개(M79 광역 폭발은 별도 예외 자산) |

## 4. 등급별 이펙트 스펙 (대/중/소)
256×256px 셀(총기 도트 시안과 동일 캔버스 기준) 안에서의 상대 크기로 잡았다. 프레임 수는 애니메이션 디자인 원칙(팔다리 최소화·낮은 프레임 예산)과 동일하게 최소 구성을 우선한다.

| 항목 | 소형 | 중형 | 대형 |
|---|---|---|---|
| 총구화염 반경 | ~20~30px, 별형 스파크 1개 | ~40~50px, 방사형 스파크 + 짧은 후광 | ~70~90px, 방사형 폭발 + 잔여 스모크 |
| 총구화염 프레임 수 | 1~2 | 2~3 | 3~4 |
| 총알 이미지 | 1px 얇은 직선형 정지 이미지, 길이 40~60px | 2px 예광선형 정지 이미지, 길이 80~120px | 굵고 존재감 있는 기본형 정지 이미지 1종 |
| 궤적 표현(코드) | 직선 트윈 | 직선 트윈 | 저격은 즉시성 직선, 샷건은 이미지 여러 개를 부채꼴로 회전 배치, 유탄은 포물선 트윈 — 전부 코드에서 각도·경로만 다르게 재생, 이미지는 3장의 대형 총알 1종 재사용 |
| 탄피 | 1개, 반짝임만 표현하고 낙하 생략 또는 2프레임 낙하 | 연사 무기는 2~4개 연속 배출, 단발형은 1개를 크게 | 큼직한 탄피 1~2개(RPK는 탄띠 연결형 다량), M79는 탄피 없음(포탄형 재장전) |
| 피격 이펙트 반경 | ~15px, 점 스파크 | ~25px, 스파크 + 파편 2~3개 | ~40~60px, 스파크 폭발 + 파편 4~5개(M79는 광역 폭발 별도, ~120px) |
| 화면 흔들림 | 없음 또는 1~2px·1프레임 | 2~3px·2프레임 | 4~6px·3프레임(AWM·M79는 최대치) |
| 파티클 컬러 수 | 2색(밝은 노랑+흰) | 3색(주황+노랑+흰) | 4색(빨강+주황+노랑+흰), 폭발류는 짙은 회색 연기색 추가 |

## 6. 도트 표현·알파 규칙 (계승)
**총기 도트 시안**·**팔다리 없는 도트 캐릭터 시안**과 동일한 규칙을 이펙트에도 그대로 적용한다.

- 중간 퀄리티로 진행할 것.
- 이진 알파(`0` 또는 `255`)만 사용, 투명 픽셀 RGB는 `0, 0, 0`으로 정리.
- 마젠타(`#FF00FF`) 단색 배경에서 생성 후 크로마키로 알파 추출, 남은 마젠타·보라 스필은 짙은 공통 외곽선 색으로 디스필.
- 그라데이션·에어브러시 명암·디더링 금지, 재질당 3~4단계 색상으로 셀 음영 처리.
- 크기 조정은 최근접 보간만 사용, 흰색·회색·마젠타 프린지와 고립 픽셀 0개를 검수 기준으로 한다.
- 총기 자체와 마찬가지로 이펙트도 거치대·잔여 구조물 없이 순수 이펙트 요소만 포함한다.

### 6-1. 캐릭터·총기 스타일 정합성 규칙

초기 머즐 플래시는 고채도 적색, 넓은 순백색 중심광, 많은 불티와 큰 연기 덩어리 때문에 캐릭터·총기보다 오래된 아케이드 도트 이펙트처럼 보였다. 후속 시안은 아래 규칙을 필수로 적용한다.

- 캐릭터의 넓고 단순한 셀 음영과 총기의 어두운 저채도 팔레트보다 이펙트가 과도하게 앞에 튀어나오지 않도록 한다.
- 순백색 중심광은 사용하지 않고 따뜻한 아이보리 `#FFF1C2`를 사용한다. 중심광 면적은 v1 대비 약 30~40% 수준으로 축소한다.
- 주색은 밝은 황색 `#F6C84A`와 낮은 채도의 주황 `#E58A36`으로 구성한다.
- 적색은 어두운 외곽 포인트 `#A94F32`로만 제한하고, 넓은 적색 면이나 선명한 빨강 테두리를 사용하지 않는다.
- 소형은 2~3색, 중형은 3색, 대형은 최대 4색으로 제한한다. 대형 마지막 프레임의 연기만 `#655B55`를 추가할 수 있다.
- 흩어지는 불티는 v1 대비 절반 이하로 줄이고, 고립된 1픽셀 대신 본체와 연결되거나 2픽셀 이상 모인 작은 군집으로 표현한다.
- 대형 연기는 마지막 프레임에만 2~3개의 단순한 덩어리로 제한한다. 폭발 구름처럼 부풀거나 셀 대부분을 차지하지 않는다.
- 뾰족한 전방위 폭발형보다 짧고 넓은 마름모·부채꼴 실루엣을 우선해 총구 섬광으로 읽히게 한다.
- 최대 섬광도 캐릭터 얼굴보다 작게 유지하며, 프레임 사이 크기 변화가 지나치게 커서 지속 화염처럼 보이지 않게 한다.

## 7. Godot 노드 구조 제안
**팔다리 없는 도트 캐릭터 시안** 6장의 "도구 분리 원칙"을 이펙트까지 확장한다.

- 캐릭터 노드 → 무기 노드(총기 도트 시안) → 이펙트 노드(이 문서) 순으로 계층을 분리한다.
- 이펙트는 총기 스프라이트가 아니라 **등급(대/중/소) 단위로 재사용되는 공용 파티클/애니메이션 리소스**로 관리한다 — 총기 12종이 아니라 등급 3종만큼만 이펙트 씬을 만들면 된다.
- 총구화염·탄도·탄피·피격·화면 흔들림은 각각 독립된 서브노드로 두어, 총기 교체 시 등급만 바꿔 끼우면 전체 이펙트 세트가 함께 바뀌도록 한다.
- Texture Filter는 `Nearest`, 화면·카메라 좌표는 정수 픽셀 기준 — 총기 도트 시안 9장과 동일 기준 재사용.

## 8. 산출물 저장 규칙 (제안)

## 9. 미확정 사항
1. ~~**총알 아키타입 세분화 여부**~~ — **확정됨.** 실제 방향·궤적은 코드로 처리하지만, 시각적 무게감과 잔상 길이는 4×4 통합 시트의 16개 셀에서 선택한다. M79 포탄은 이 총알 시트에 포함하지 않고 별도 포물선 발사체로 제작한다.
2. **SPAS-12 최종 등급** — 4장에서 중형/대형 경계 사례로 남겨둠, 플레이 테스트 후 확정 필요.
3. **탄피 이미지의 후속 진행 여부** — 3장에서 이번 배치 제외로 정했으나, 실제로 언제·몇 장을 추가할지는 미정.
4. **플레이어 구분 색과의 관계** — **캐릭터 디자인** 페이지 8장에서 논의했던 마젠타 마스킹(부양 장치 오라)이 총기 컨셉으로 전환되며 그대로 쓸 수 있는지 미확정. 이펙트(총구화염 등)에 플레이어색을 얹을지, 총기 자체에 얹을지, 아예 별도 표시(캐릭터 위 네임태그 등)로 대체할지 결정 필요.
5. **원거리 공격 애니메이션과의 연결** — **캐릭터 디자인** 페이지 3~4장에서 정의한 "몸통 움찔 + 이펙트" 원거리 공격 원칙이 총기 컨셉에서도 그대로 유지되는지, 아니면 반동 표현이 총기 자체의 위치·회전 트윈으로 옮겨가는지 재정리 필요.

## 10. 머즐 플래시 3타입 통합 스프라이트 시트 v2 — 스타일 정합성 수정

소형·중형·대형 머즐 플래시의 점화부터 소멸까지를 한 장에서 명확히 분리한 4열×3행 시트다.[^1]

| 행 | 타입 | 사용 프레임 | 프레임 흐름 | 공백 셀 |
|---|---|---:|---|---|
| 1행 | 소형 | 2 | 점화 스파크 → 짧은 최대 섬광 | 3·4열 |
| 2행 | 중형 | 3 | 점화 → 최대 방사형 섬광 → 축소·감쇠 | 4열 |
| 3행 | 대형 | 4 | 점화 → 확장 → 최대 폭발 → 연기·잔불 소멸 | 없음 |

- **전체 규격**: 1024×768 px RGBA
- **셀 규격**: 256×256 px, `hframes = 4`, `vframes = 3`
- **재생 방향**: 각 행을 왼쪽에서 오른쪽으로 재생하며, 사용하지 않는 공백 셀은 애니메이션에서 제외한다.
- **타입 분리**: 각 타입은 한 행만 사용하고 다른 행으로 이펙트 픽셀이 넘어가지 않는다. 프레임 사이에도 충분한 투명 여백을 둔다.
- **부착 기준**: 이펙트가 화면 오른쪽으로 뻗도록 구성하며, 총구 접점은 각 셀의 왼쪽 영역에 고정한다. 실제 총기별 미세 위치는 Godot 이펙트 노드 오프셋으로 조절한다.
- **색상**: 아이보리 중심광·낮은 채도의 노랑·주황을 기본으로 하고 적색 면적을 최소화한다. 대형 마지막 프레임에만 작은 저채도 회갈색 연기 2~3덩어리를 허용한다.
- **알파 처리**: 중간 퀄리티 생성본을 순수 마젠타 `#FF00FF` 마스터로 평탄화한 후 키 추출했다. 최종 알파는 `0/255`, 투명 픽셀 RGB는 `0, 0, 0`이다.
- **디노이징 검수**: 단일 고립 픽셀을 제거하고 2픽셀 이상 연결된 불티 군집만 유지했다. 모든 사용 프레임은 256×256px 셀 내부에 여백을 확보하며 공백 셀 3개는 완전 투명이다.
- **마젠타 마스터**: `assets/muzzle-flash-3types-v2-stylematch-magenta-master.png`
- **최종 파일**: `assets/muzzle-flash-3types-v2-stylematch-alpha-denoised.png`

Godot에서 행별 애니메이션 프레임 인덱스는 다음과 같다.

- 소형: `0, 1`
- 중형: `4, 5, 6`
- 대형: `8, 9, 10, 11`

## 11. 피격 임팩트 3타입 통합 스프라이트 시트 v1

총알이 충돌한 한 점을 중심으로 짧은 스파크와 고형 파편이 방사된 뒤 사라지는 소형·중형·대형 공용 피격 시트다.[^2]

| 행 | 타입 | 사용 프레임 | 프레임 흐름 | 공백 셀 |
|---|---|---:|---|---|
| 1행 | 소형 | 2 | 작은 접촉광 → 축소·소멸 | 3·4열 |
| 2행 | 중형 | 3 | 접촉 스파크 → 파편 2~3개 확산 → 감쇠 | 4열 |
| 3행 | 대형 | 4 | 압축된 접촉 → 확장 → 파편 4~5개 최대 확산 → 잔여 파편 소멸 | 없음 |

- **전체 규격**: 1024×768 px RGBA, 4열×3행
- **셀 규격**: 256×256 px, `hframes = 4`, `vframes = 3`
- **형태 구분**: 머즐 플래시처럼 한 방향으로 뻗는 불꽃이나 긴 꼬리를 사용하지 않고, 셀 중앙의 고정 충돌점을 기준으로 짧은 각진 스파크와 파편을 여러 방향으로 배치했다.
- **크기 기준**: 소형 반경 약 15px, 중형 약 25px, 대형 약 40~60px의 상대 크기 차이를 유지한다.
- **팔레트**: 머즐 플래시 v2와 같은 아이보리·저채도 황색·주황·적갈색을 사용하고, 고형 파편에만 회갈색 `#655B55`를 사용한다. 순백색과 고채도 적색은 사용하지 않는다.
- **빈 공간**: 모든 사용 프레임은 셀 내부에 최소 24px 수준의 안전 여백을 확보하며 공백 셀 3개는 완전 투명이다.
- **알파·디노이징**: 중간 퀄리티 생성 → 순수 마젠타 `#FF00FF` 키 추출 → 승인된 5색 팔레트 정규화 → `0/255` 이진 알파 → 단일 고립 픽셀 제거 순으로 처리했다.
- **마젠타 마스터**: `assets/impact-3types-v1-magenta-master.png`
- **최종 파일**: `assets/impact-3types-v1-magenta-alpha-denoised.png`

Godot 프레임 인덱스:

- 소형: `0, 1`
- 중형: `4, 5, 6`
- 대형: `8, 9, 10, 11`

## 12. 총알·예광선 4아키타입 × 4길이 통합 시트 v1

총기별 체감과 속도 표현을 나눌 수 있도록 4개의 투사체 아키타입을 점형부터 긴 잔상까지 4단계로 제작했다.[^3]

| 행 | 아키타입 | 적용 후보 | 시각 특징 |
|---|---|---|---|
| 1행 | 경량 권총/SMG탄 | M1911, Glock 18, MP5 | 가장 얇고 작은 아이보리·황색 예광선 |
| 2행 | 표준 소총탄 | Thompson, M4A1, AK-47, Winchester | 경량탄보다 굵고 밝은 표준형 |
| 3행 | 중량/저격탄 | RPK, AWM | 회갈색 금속 탄두와 굵은 에너지 잔상 |
| 4행 | 산탄 펠릿 | 더블배럴, SPAS-12 | 3개 펠릿이 짧게 평행하다가 긴 단계에서 좁게 분산 |

열은 모든 행에서 공통이다.

1. 1열: 점형·탄두형, 약 12~24px
2. 2열: 짧은 잔상, 약 40~60px
3. 3열: 중간 잔상, 약 80~120px
4. 4열: 긴 잔상, 약 150~190px

- **전체 규격**: 1024×1024 px RGBA, 4열×4행
- **셀 규격**: 256×256 px, `hframes = 4`, `vframes = 4`
- **진행 방향**: 탄두가 화면 오른쪽, 잔상이 왼쪽을 향하도록 전 셀을 통일했다. 왼쪽 발사는 Godot의 수평 반전으로 처리한다.
- **사용 방식**: 한 셀을 정지 투사체로 선택하거나, 같은 행의 `0→1→2→3열`을 짧게 재생해 속도 증가에 따라 잔상이 길어지는 표현으로 사용할 수 있다.
- **팔레트**: 머즐 플래시·임팩트와 같은 아이보리 `#FFF1C2`, 황색 `#F6C84A`, 주황 `#E58A36`, 적갈색 `#A94F32`, 회갈색 `#655B55`만 사용한다.
- **알파·디노이징**: 중간 퀄리티 생성 → 순수 마젠타 `#FF00FF` 키 추출 → 승인된 5색 정규화 → `0/255` 이진 알파 → 경량·소총·저격 셀은 가장 큰 연결 군집 하나, 산탄 셀은 가장 큰 세 군집만 유지하는 순서로 처리했다.
- **마젠타 마스터**: `assets/bullet-archetypes-4x4-v1-magenta-master.png`
- **최종 파일**: `assets/bullet-archetypes-4x4-v1-magenta-alpha-denoised.png`

Godot 행별 프레임 인덱스:

- 경량탄: `0, 1, 2, 3`
- 표준 소총탄: `4, 5, 6, 7`
- 중량/저격탄: `8, 9, 10, 11`
- 산탄 펠릿: `12, 13, 14, 15`
