# 십이간지 도트 캐릭터 시안 — 팔다리 없는 어깨띠형

## 1. 시안 개요

십이간지 12종을 작은 화면에서도 즉시 구분할 수 있도록 단순한 도트 캐릭터로 구성한다.[^1] 캐릭터 본체에는 팔다리와 도구를 두지 않고, 종별 머리·몸통 특징과 공통 어깨띠만 남긴다.

이 시안은 대기 상태의 기본 외형 기준이다. 총, 도끼, 지팡이와 같은 게임 도구는 캐릭터 이미지에 합치지 않고 별도 노드·스프라이트로 관리한다.

## 2. 스프라이트 시트 규격

| 항목 | 규격 |
|---|---|
| 파일 | `assets/Animal_12_limbless_sash_pixel-v1.png` |
| 전체 크기 | 1024×768 px |
| 배열 | 4열×3행 |
| 셀 크기 | 256×256 px |
| 색상 형식 | RGBA |
| 알파 | 0 또는 255의 이진 알파 |
| 셀 여백 | 모든 셀 경계에 투명 여백 확보 |

배치 순서는 다음과 같다.

1. 첫째 줄: 쥐, 소, 호랑이, 토끼
2. 둘째 줄: 뱀, 용, 말, 양
3. 셋째 줄: 원숭이, 닭, 진돗개, 돼지

## 3. 공통 신체 구조

- 팔, 손, 다리, 발과 발바닥을 그리지 않는다.
- 머리와 둥근 몸통이 연결된 캡슐형 실루엣을 기본으로 한다.
- 팔다리가 없어도 종을 알아볼 수 있도록 귀, 뿔, 꼬리와 얼굴 형태를 우선한다.
- 캐릭터별 몸통 폭과 머리 크기는 비슷하게 맞추되, 토끼 귀와 소 뿔처럼 필요한 돌출부는 허용한다.
- 바닥 그림자, 받침대와 부유 효과는 기본 캐릭터 시트에 포함하지 않는다.

| 사(巳) | 뱀 | 팔다리 없는 세로 몸통, 녹색 등, 노란 배, 붉은 혀 |

## 5. 공통 어깨띠

모든 캐릭터에는 장식 없는 짙은 갈색 천 어깨띠 하나만 적용한다.

- 화면을 바라보는 시점 기준 **왼쪽 위 어깨에서 오른쪽 아래 몸통으로 내려가는 `＼` 방향**이다.
- 캐릭터의 실제 좌우 방향이나 바라보는 방향과 관계없이 화면상의 대각선 방향을 통일한다.
- 몸통 앞면을 가로지르되 얼굴, 눈, 코와 종별 핵심 무늬를 가리지 않는다.
- 캐릭터마다 폭과 색상을 동일하게 유지한다.
- 버클, 주머니, 배지, 탄띠, 무기 고정부와 매듭을 추가하지 않는다.
- 뱀도 왼쪽 위 몸통에서 오른쪽 아래 몸통으로 같은 방향의 띠를 적용한다.

## 6. 도구 분리 원칙

캐릭터에 붙어 있던 총, 도끼, 지팡이, 몽둥이, 발사기 등의 도구는 모두 제거한다.

- 캐릭터 기본 이미지에는 어깨띠까지만 포함한다.
- 무기나 도구는 캐릭터와 독립된 스프라이트로 제작한다.
- 게임에서는 캐릭터 노드 아래 별도 장비 노드로 부착한다.
- 장비 교체, 회전과 발사 애니메이션이 캐릭터 원본 이미지를 변경하지 않도록 한다.
- 도구가 없는 상태에서도 12종의 실루엣이 완결되어 보여야 한다.

## 7. 도트 표현 규칙

- 낮은 해상도에서 읽히는 큰 픽셀 군집을 사용한다.
- 곡선을 부드럽게 흐리지 않고 계단형 픽셀로 정리한다.
- 재질당 기본색, 밝은 면, 어두운 면을 포함해 약 3~4단계 색상을 사용한다.
- 연속 그라데이션, 에어브러시 명암과 과도한 디더링을 사용하지 않는다.
- 외곽선은 검정 또는 매우 어두운 고유색으로 통일한다.
- 눈과 콧구멍처럼 작은 특징은 1~3픽셀 단위의 단순한 형태로 표현한다.
- 수염이나 용 수염 등 얇은 특징은 고립 픽셀이 아니라 연결된 픽셀 군집으로 만든다.

## 8. 알파 및 디노이징

- 배경은 실제 투명으로 저장한다.
- 알파 값은 완전 투명 `0` 또는 완전 불투명 `255`만 사용한다.
- 투명 픽셀의 RGB 값은 `0, 0, 0`으로 비워 밝은 프린지를 방지한다.
- 체크무늬, 흰색 테두리, 반투명 안티앨리어싱과 고립된 점 픽셀을 제거한다.
- 캐릭터의 수염, 꼬리 끝과 뿔처럼 의도된 얇은 부분은 노이즈로 판단해 삭제하지 않는다.
- 크기 변경이 필요할 때는 최근접 보간을 사용한다.
- 중간 퀄리티로 마젠타를 활용해 알파를 빼는 것을 기억한다.

## 9. Godot 적용 기준

- Texture Filter는 `Nearest` 또는 프로젝트 설정상 필터 비활성화를 사용한다.
- 스프라이트 시트는 `hframes = 4`, `vframes = 3`으로 분할한다.
- 캐릭터 프레임 인덱스는 왼쪽에서 오른쪽, 위에서 아래 순서로 `0~11`을 사용한다.
- 화면 배율은 가능하면 정수 배율로 설정해 픽셀 흔들림을 방지한다.
- 위치와 카메라 좌표도 최종 렌더링 단계에서 정수 픽셀에 맞춘다.
- 어깨띠는 기본 외형에 포함하지만 도구·무기·발사 효과는 별도 노드로 관리한다.

## 10. 현재 결정 사항

- 이 시안을 팔다리 없는 캐릭터의 기본 외형으로 사용한다.
- 캐릭터 본체에는 어깨띠 외의 장비를 합치지 않는다.
- 어깨띠 방향은 12종 모두 화면 기준 `＼`로 고정한다.
- 후속 이동 애니메이션도 팔다리를 새로 만들지 않고 몸통의 눌림, 기울기와 반동으로 표현한다.

## 11. 외곽 디노이징·마젠타 알파 추출 시안 v2

기존 v1에서 캐릭터 테두리 바깥에 붙어 있던 잡픽셀과 밝은 프린지를 정리한 중간 퀄리티 시안이다.[^2]

- **형태 유지**: 12종의 배치, 팔다리 없는 캡슐형 몸통, 종별 식별 요소와 공통 `＼` 방향 어깨띠를 유지했다.
- **마젠타 키**: 순수 마젠타 `#FF00FF` 배경의 중간 마스터를 만든 뒤 외곽 연결 영역만 크로마 키로 제거했다.
- **디스필**: 가장자리에 남은 보라·마젠타 계열 색 번짐을 공통 짙은 외곽선 색으로 치환했다.
- **알파**: 최종본은 1024×768 px RGBA이며 알파 값을 `0` 또는 `255`로 제한하고, 투명 픽셀 RGB를 `0, 0, 0`으로 정리했다.
- **도트 보존**: 크기 정규화에는 최근접 보간만 사용했으며 수염, 꼬리, 뿔과 용 수염처럼 연결된 얇은 특징은 유지했다.
- **파일**: 마젠타 마스터는 `assets/Animal_12_limbless_sash_pixel-v2-magenta-master.png`, 실제 게임용 알파 결과는 `assets/Animal_12_limbless_sash_pixel-v2-alpha-denoised.png`이다.
