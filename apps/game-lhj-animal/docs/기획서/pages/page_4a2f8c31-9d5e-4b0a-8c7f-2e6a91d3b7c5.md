# 애니메이션 디자인

## 1. 기본 원칙 — 제작 난이도를 낮추는 방향
- **idle 루프 애니메이션은 만들지 않는다.** 가만히 있을 때는 **캐릭터 디자인** 페이지 5-3의 기본 서 있는 정지 포즈 1장을 그대로 쓴다 — 숨쉬기 등 미세 반복 동작을 위한 별도 루프를 원화·리깅할 필요가 없다.
- 대신 **한 자리에 3~5초 이상 멈춰 있으면 파티클 이펙트를 재생**해서 "가만히 있어도 심심해 보이지 않는" 효과를 애니메이션이 아닌 이펙트로 대체한다 — 이펙트 목록은 **파티클 디자인** 페이지 참고. 파티클은 정지 포즈 위에 얹기만 하면 되므로 스켈레톤 애니메이션보다 제작 비용이 훨씬 낮다.
- **이동 애니메이션은 걷기/뛰기를 구분하지 않고 "뛰는 모션" 하나로 통일**한다. 서서 뛰어다니는 느낌을 기본값으로 잡고, 이동 상태 전체(느린 이동이든 빠른 이동이든)를 이 사이클 하나의 재생 속도만 조절해서 커버한다 — 워크 사이클과 런 사이클을 별도로 만들지 않아도 된다.

---

## 2. 공용 애니메이션 (전 캐릭터 1세트로 재사용)
| # | 애니메이션 | 용도 |
|---|---|---|
| 1 | 기본 서 있는 자세 (정지 포즈) | 대기 상태 전체를 담당 — idle 루프 대체 |
| 2 | 이동(뛰기) 모션 | 워크·런 구분 없이 이동 전체를 커버하는 단일 사이클 |
| 3 *(제안)* | 성공 리액션 | 미니게임 결과 화면 공통 재사용 — 예: 방방 뛰며 양팔 들기 |
| 4 *(제안)* | 실패 리액션 | 미니게임 결과 화면 공통 재사용 — 예: 어깨 축 늘어뜨리기 |
| 5 *(제안)* | 캡슐 등장 모션 | 캡슐을 뽑아 미니게임에 입장할 때 "짠" 하고 튀어나오는 연출, 세계관의 캡슐뽑기 컨셉과 직결되므로 전 캐릭터 공통으로 만들어두면 재사용 가치가 높음 |

3~5번은 원문에는 없었지만, **미니게임 디자인** 페이지에서 이미 "입장→플레이→결과"라는 공통 플로우가 필요하다고 짚었던 부분과 맞물려 있어 애니메이션 목록에도 반영해봤다.

## 3. 동물별 개별 액션 애니메이션
공용 2종(정지·이동) 외에, 미니게임 메커닉을 그대로 보여주는 **동물별 전용 액션 1개**가 필요해 보인다. **미니게임 디자인** 페이지의 동물-직업-메커닉 표를 그대로 애니메이션 단위로 옮긴 것이라 새 개념은 아니고, "그래서 실제로 몇 개를 만들어야 하는가"를 리스트업한 것이다.

| 동물 | 개별 액션 애니메이션 |
|---|---|
| 카피바라 | (미니게임 없는 리더 NPC) 인사/환영 제스처 정도만 있으면 충분, 필수는 아님 |
| 악어 | 태엽을 입으로 물고 데스롤(회전)하는 액션 |
| 새 | 날개짓하며 날아오르는 비행 액션 (지상 이동과 별도 상태) |
| 비버 | 이빨로 나무를 빠르게 쏠아 다듬는 반복 액션 |
| 다람쥐 | 볼주머니에 물건을 넣고 빼는 액션 |
| 두더지 | 땅을 파고 들어갔다 나오는 액션 (화면에서 사라짐/등장 포함) |
| 문어 | 여러 팔을 동시에 휘두르는 멀티태스킹 액션 |
| 캥거루 | 배주머니에 짐을 담고 크게 점프하는 액션 |
| 펠리컨 | 부리로 물건을 받아 담는 캐치 액션 |
| 여우 | 손짓하며 흥정하는 제스처 액션 |
| 곰 | 발톱으로 벌집을 긁는 액션 |
| 코알라 | 나무(혹은 소품)에 매달려 늘어지는 액션 |
| 수달 콤비 | 둘이 손을 잡고 동기화되어 움직이는 협동 액션 |
| 염소 | 박치기 돌진 액션 |
| 플라밍고 | 외발로 서서 균형 잡는 홀드 액션 |
| 스컹크 | 냄새 스프레이를 뿌리는 액션 |
| 앵무새 | 부리를 여닫으며 소리를 흉내 내는 액션 |
| 코뿔소 | 돌진 차지 액션 |
| 판다 | 빠르게 먹는(연타) 액션 |

카피바라를 제외하면 사실상 "미니게임 1개 = 개별 액션 1개"로 딱 떨어진다 — **미니게임 디자인** 페이지의 확장 후보 표가 곧 이 애니메이션 목록의 소스가 되므로, 두 페이지를 함께 관리하는 게 좋다.

## 4. 추가로 정리가 필요해 보이는 항목 (AI 제안)
1. **개별 액션 애니메이션의 실제 우선순위** — 3장에서 19종 전체 목록은 뽑았지만, **미니게임 디자인** 페이지에서 언급된 "출시 시점 미니게임 개수"가 정해져야 실제로 몇 개의 개별 액션부터 제작할지 정해진다.
2. **협동 애니메이션(수달 콤비)의 리깅 방식** — 3장의 수달 콤비 동기화 액션은 캐릭터 2개가 하나의 애니메이션처럼 맞물려야 하므로, 일반 동물의 단일 리그와는 제작 방식이 달라질 수 있다 — 별도 검토 필요.
3. **성공/실패/등장 애니메이션의 실제 채택 여부** — 2장의 3~5번은 AI 제안 상태라, 정말 전 캐릭터 공통으로 갈지 동물별로 다르게 갈지 결정이 필요하다.
