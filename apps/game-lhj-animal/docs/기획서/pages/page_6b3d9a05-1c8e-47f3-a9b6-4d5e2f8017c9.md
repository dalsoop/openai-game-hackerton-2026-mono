# 파티클 디자인

## 1. 왜 파티클인가 — idle 애니메이션 대체
**애니메이션 디자인** 페이지 1장에서 정한 원칙대로, idle 루프 애니메이션은 만들지 않고 정지 포즈 1장만 사용한다. 그 대신 **한 자리에 3~5초 이상 멈춰 있으면 파티클 이펙트를 재생**해서 캐릭터가 심심해 보이지 않게 한다. 파티클은 정지 포즈 위에 얹기만 하면 되므로 스켈레톤 애니메이션보다 제작 비용이 훨씬 낮다.

|---|---|
| 물음표(?) | 멍한 느낌, 종과 무관하게 통용되는 가장 범용적인 표현 |
| Zzz (졸음 기호) | 지루하거나 졸린 느낌, 역시 종 무관 |

## 3. 동물별 개별 파티클
습성·성격이 뚜렷한 동물부터 우선 개별 파티클을 적용하고, 나머지는 2장의 공용 파티클로 채우는 방식을 제안한다.

| 동물 | 개별 파티클 | 왜 개별로 제안하는가 |
|---|---|---|
| 카피바라 | 온천 김/유자 | 온천 밈과 리더 캐릭터 아이덴티티를 이펙트로도 강화 |
| 비버 | 톱밥 날림 | 목공 습성과 직접 연결 |
| 다람쥐 | 도토리가 머리 위로 통통 튐 | 저장 습성 + 걱정 많은 성격을 동시에 표현 |
| 두더지 | 발밑에 흙무더기가 조금씩 쌓임 | 땅 파는 습성과 연결 |
| 곰 | 꿀방울이 똑똑 떨어짐 | 양봉업 아이덴티티와 연결 |
| 문어 | 먹물 방울이 보글보글 | 종 특성(먹물)을 활용한 개그 포인트 |
| 스컹크 | 초록색 냄새 파동 | 냄새 개그 캐릭터성과 가장 직접적으로 연결 |
| 플라밍고 | 깃털이 하늘하늘 떨어짐 | 우아한 척하는 성격과 어울리는 잔잔한 연출 |
| 판다 | 입가에 붙은 대나무 잎 | "먹는 것 앞에서만 진지해지는" 캐릭터성과 연결 |

> 목록에 없는 동물(악어, 새, 캥거루, 펠리컨, 여우, 코알라, 수달 콤비, 염소, 앵무새, 코뿔소 등)은 습성상 뚜렷한 파티클감이 바로 떠오르지 않아 우선 2장 공용 파티클로 채워도 무방하다. 나중에 좋은 아이디어가 나오면 개별로 승격.

## 4. 추가로 정리가 필요해 보이는 항목 (AI 제안)
1. **재생 트리거 세부 규칙** — "3~5초"의 정확한 기준값, 이동/조작 입력이 들어오면 즉시 파티클이 끊기는지, 반복 재생 주기는 얼마인지 등 구체적인 트리거 로직이 아직 없다.
2. **파티클과 컬러 예산의 관계** — **캐릭터 디자인** 페이지 6장의 5~6색 예산은 캐릭터 본체 기준이라, 파티클 자체 색상(예: 스컹크 냄새의 초록색)이 이 예산에 포함되는지 별도 취급인지 정리가 필요하다.
3. **굿즈/정적 이미지에서의 처리** — 파티클은 실시간 이펙트라 정지 이미지(굿즈, 프로필 아이콘 등)에는 표현이 안 되므로, 그런 매체에서는 어떤 포즈를 기본으로 쓸지 별도 확인이 필요하다.
