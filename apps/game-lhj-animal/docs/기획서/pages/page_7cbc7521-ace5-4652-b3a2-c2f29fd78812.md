# 배경 디자인

## 1. 공간적 배경
- 레퍼런스는 주토피아류의 "다양한 동물이 함께 사는 도시" + 유저가 낯선 세계로 들어가는 **이세계물** 구조.
- **세계관** 페이지 1장에서 제안한 "캡슐 = 마을 속 구역" 구조를 적용하면, 주토피아식 세계관과 이세계 진입 클리셰가 자연스럽게 결합된다.

---

## 2. 공간 구조 — 3단계 화면
**게임 시스템** 페이지의 코어 루프("로비(마을)→캡슐머신→미니게임→결과→로비 순환")를 배경 공간으로 그대로 옮기면 아래 3단계가 나온다. 지금까지는 텍스트 설정뿐이었는데, 실제로 화면이 몇 종류 필요한지 정리해본다.

### 2-1. 캡슐기계 화면
- **화면 전체를 가득 채우는 풀스크린 연출**로 계획 중 — 마을의 탑다운 시점과는 완전히 다른, 정면 클로즈업 연출 레이어.
- 코어 루프상 "캡슐 뽑기" 단계이자 미니게임 입장 게이트. 세계관 페이지 1장의 "캡슐=마을 구역" 컨셉이 실제 화면으로 구현되는 지점이라, 이 게임의 첫인상을 좌우하는 화면이기도 하다.
- 검토가 필요해 보이는 지점:
  - 앱 최초 실행 시 타이틀 화면 역할까지 겸하는지, 아니면 마을 진입 후에만 접근하는 화면인지.
  - 마을 안에 물리적으로 놓인 오브젝트(다가가면 확대되어 풀스크린 전환)인지, 로비에서 버튼 한 번으로 진입하는 완전히 독립된 화면인지 — 전자는 몰입감이 좋고, 후자는 구현이 단순하다.
  - 손잡이를 돌리고 → 캡슐이 나오고 → 캡슐이 열리는 상호작용 시퀀스가 필요해 보인다. **애니메이션 디자인** 페이지의 "캡슐 등장 모션"과 이어지는 연출.
  - 캡슐 기계가 미니게임마다 여러 대 있는지, 한 대에서 랜덤으로 다양한 캡슐이 나오는지 — 후자가 마을 맵을 단순하게 유지하기엔 유리하다.

### 2-2. 마을 — 동물 세상과의 첫 만남 + 로비(허브)
- 이 공간은 **두 역할을 동시에** 한다: (1) 유저가 처음 이세계에 들어와 동물 세상을 만나는 오프닝 무대, (2) 이후 반복 방문하는 로비/허브. 하나의 맵을 두 목적으로 재사용하는 셈이라, 설계 시 이 둘을 같이 고려해야 한다.
- 시점은 3장 아트 스타일의 탑다운을 그대로 적용.
- 세계관 페이지 1장의 "카피바라 마을을 중심 허브로, 각 캡슐이 개별 직업 공간으로 연결" 구조를 그대로 따른다.
- 검토가 필요해 보이는 지점:
  - 첫 진입 시 플레이어가 서는 시작 지점 — 카피바라와 처음 마주치는 장소(광장 등)가 있으면 오프닝 연출이 자연스러워진다.
  - 마을 규모 — 화면 하나에 다 들어오는 작은 광장형인지, 스크롤/이동이 필요한 넓은 맵인지.
  - 캡슐머신(들)의 배치 방식 — 광장 둘레에 상점처럼 늘어놓을지, 구역별로 나눠 걸어가야 하는 배치로 할지.
  - 세계관 페이지 2장(빙의 vs 변장)이 정해지면, 마을 최초 진입 연출(오프닝 컷씬 유무 등)도 함께 정해진다.

### 2-3. 개별 미니게임 공간
- 세탁소, 목공소, 어시장 등 직업별 작업 공간. 마을과는 성격이 다른 공간이라는 점이 핵심이다 — **미니게임 디자인** 페이지의 "샌드박스+챌린지, 난장판" 톤에 맞추려면 자유 탐험형 맵이 아니라 **경계가 뚜렷한 아레나형 공간**(Fall Guys류)이 되어야 다인원 충돌·훼방 요소가 잘 살아난다.
- 시점은 마을과 동일한 탑다운을 기본으로 하되, 코뿔소 데몰리션처럼 화면을 넓게 써야 하는 미니게임은 예외적으로 화각을 다르게 가져갈 수도 있다.
- 각 공간의 구체적인 비주얼(세탁소 내부, 어시장 좌판 등)은 아직 텍스트 설정뿐이라 4장 TODO에 남겨둔다.

## 3. 아트 스타일 — 맵/카메라 시점
- 캐릭터가 상하좌우로 자유롭게 돌아다니는 2D 맵은 보통 **탑다운(Top-down) 뷰** 혹은 **쿼터뷰(3/4 시점)**로 분류한다.
- 어몽어스는 완만하게 위에서 내려다보는 탑다운에 가까우며, 캐릭터는 회전 스프라이트 없이 **좌우 반전(플립)만으로 이동 방향을 표현**하는 미니멀 애니메이션 방식을 쓴다.
- 이 방식은 스프라이트 수를 크게 줄일 수 있어, 등장 동물 종류가 많은 우리 기획(1미니게임 = 1동물)에 특히 유리하다 — 동물마다 정면/측면 2~3장 정도의 스프라이트만으로 이동 애니메이션 구현이 가능하다.
- 2-1의 캡슐기계 화면만은 이 탑다운 원칙에서 벗어나는 예외 — 정면 클로즈업 연출이라는 점에 유의.
- 캐릭터 실루엣 스타일(캡슐형 바디 등)은 **캐릭터 디자인** 페이지 참고.

## 4. 추가로 정리가 필요해 보이는 항목 (AI 제안)
> 2장에서 공간을 3단계로 정리하면서 세부 사항 위주로 갱신했다.

1. **마을 맵의 실제 배치도** — 2-2에서 역할은 정리됐지만, 실제 맵 배치(원형/일자형/자유탐험형 등)나 이동 방식은 아직 없다.
2. **개별 미니게임 공간의 비주얼 컨셉** — 세탁소, 우편함, 목공소 등 각 공간의 실제 배경 아트(레이아웃, 소품, 장애물 배치)가 텍스트 설정 외에는 없다.
3. **배경 색감 방향** — **캐릭터 디자인** 페이지의 컬러 팔레트 설계 시 "배경 톤이 아직 확정되지 않은 상태"라고 명시돼 있는 만큼, 배경 자체의 색감·명도 기준이 필요하다. 캐릭터 팔레트와 겹치지 않는 범위로 잡아야 한다.
4. **시간대/날씨/계절 연출 여부** — 마을에 낮/밤이나 계절 변화를 줄지 미정.
5. **캡슐기계 화면의 UI 결합 방식** — 2-1에서 풀스크린으로 정했지만, 뽑기 버튼·보유 재화 표시 같은 UI 요소를 이 화면 안에 어떻게 얹을지는 아직 없다.
6. **레퍼런스 이미지 부재** — 현재 배경 관련 내용은 텍스트(주토피아 언급)뿐이고 실제 참고 이미지가 없다.
