# game-lhj-animal

이현진(lhj) 신규 게임. 현재는 아트 작업 준비 단계 — 빈 Godot 4 프로젝트만 세팅됨.

```bash
godot --path .   # 에디터로 열기
```

## 기획서

`docs/기획서/` — FigixNote 원본을 그대로 복사해온 것. `pages/*.md` 가 실제 내용
(세계관 / 캐릭터 디자인 / 의상 디자인 / 애니메이션 디자인 / 파티클 디자인 /
배경 디자인 / 미니게임 디자인 / 게임 시스템), 어느 페이지가 어떤 제목인지는
`pages.json` 참고. 이미지 등 첨부는 `assets/`.
