# 화면 흐름 재설계 — 다굴(Gang-Up)

## 현재 문제

### 1. 이중 진입
HTML 로딩 페이지(`index.html`)가 타이틀과 프로그레스 바를 보여준 뒤, Godot가 로드되면 곧바로 로비가 뜬다. 사용자는 "두 번 들어가는" 느낌을 받는다. HTML 화면은 단순 로딩 스피너 역할만 하고, Godot 측 첫 화면에는 도입부가 없다.

### 2. 화면 뎁스 부재
현재 흐름:
```
[HTML 로딩] → [로비 (이름+방 목록+방 만들기+연습)] → [대기실] → [게임] → [로비]
```
로비 하나에 모든 기능이 몰려 있어서 첫인상이 산만하다. 이름 입력, 방 만들기, 방 목록, 연습, 관전이 한 화면에 있다.

---

## 업계 레퍼런스

### 디아블로 2 (뎁스 깊은 예)
```
타이틀(시네마틱) → 싱글/멀티 선택 → 캐릭터 선택 → 로비(채널/채팅) → 방 생성/참가 → 로딩 → 게임
```
각 단계에서 하나의 결정만 내리고, 다음으로 넘어간다. 뒤로 가기가 자유롭다.

### Among Us / Fall Guys (파티 게임 — 가장 유사)
```
타이틀 → 메인 메뉴(온라인/로컬) → 방 생성 또는 코드 입력 → 대기실 → 게임
```
Among Us는 로비에 방 목록이 없고, 코드로 참가한다. Fall Guys는 매치메이킹이라 방 개념이 없다.

### io 게임 (surviv.io, agar.io — 브라우저 배틀로얄)
```
[HTML 타이틀+이름 입력+PLAY 버튼] → [바로 게임 또는 매칭]
```
io 게임은 반대로 뎁스가 거의 없다. HTML 한 페이지에서 이름 입력하고 PLAY 누르면 바로 들어간다. 방 개념이 없거나 자동 매칭이다.

**다굴의 위치**: io 게임과 Among Us 사이. 방 시스템이 있으니 io 게임처럼 한 방에 끝낼 수 없고, 디아블로처럼 깊을 필요도 없다.

---

## 제안하는 흐름

```
[HTML 타이틀 + 로딩] → [인트로(이름 입력 + 바로 시작)] → [로비(방 목록)] → [대기실] → [게임] → [결과] → [로비]
```

### 흐름 비교

| 현재 | 제안 |
|---|---|
| HTML이 별도 타이틀 역할 | HTML과 Godot 인트로가 자연스럽게 이어짐 |
| 로비에 이름+방 목록+버튼 전부 | 인트로에서 이름+시작, 로비는 방 목록만 |
| 게임 끝나면 바로 로비 | 결과 화면 → 로비 |

---

## 화면별 와이어프레임

### 화면 0: HTML 로딩 (index.html — 수정)

현재 `index.html`의 `#status` 오버레이를 그대로 활용하되, 세계관 분위기를 강화한다.

```
┌──────────────────────────────────────┐
│                                      │
│           [아이콘/로고]               │
│                                      │
│         다굴 같이하기                 │
│      8명 · 한 판 · 마지막 한 명       │
│                                      │
│      ████████████░░░░░ 63%           │
│                                      │
│       "강해 보이면 모두의 적"          │  ← 한 줄 태그라인 추가
│                                      │
└──────────────────────────────────────┘
```

변경점:
- 태그라인 1줄 추가 (게임 컨셉 전달)
- 프로그레스 바 아래에 퍼센트 표시
- 배경색/그라디언트는 현재 것 유지 (이미 적절)
- Godot 로드 완료 → `#status` 제거 후 Godot가 인트로를 보여줌

### 화면 1: 인트로 (Godot — 신규, flow_screens에 `&"intro"` 페이지)

현재 `_intro`가 빈 Control이다. 여기에 이름 입력 + 시작 버튼을 넣는다.

```
┌──────────────────────────────────────┐
│                                      │
│                                      │
│            다 굴                     │
│     GANG UP — 8인 배틀로얄            │
│                                      │
│        ┌──────────────┐              │
│        │ 닉네임 입력    │              │
│        └──────────────┘              │
│                                      │
│        [ 방 찾기 (온라인) ]            │  ← 메인 버튼 (BLUE)
│        [ 바로 시작 (연습) ]            │  ← 서브 버튼 (GREEN)
│                                      │
│                   [조작법] [설정]      │  ← 우하단 작게
│                                      │
└──────────────────────────────────────┘
```

동작:
- **"방 찾기"** → `show_page(&"lobby")` — 허브 연결 시작 + 로비로 이동
- **"바로 시작"** → 로컬 매치 바로 시작 (현재 "연습하기" 버튼과 동일)
- **"조작법"** → how_to_play 팝업
- **"설정"** → 설정 팝업
- 이름은 로비에서도 변경 가능하게 유지

### 화면 2: 로비 (lobby_builder — 수정)

인트로에서 이름 입력과 연습 버튼을 가져갔으니, 로비는 **방 목록에 집중**한다.

```
┌──────────────────────────────────────┐
│ [← 뒤로]  다굴 로비  [새로고침] [설정]│
│ 연결 상태: 로비 ●                     │
├──────────────────────────────────────┤
│                                      │
│  열린 방                              │
│  ┌────────────────────────────────┐  │
│  │ 호랑이방    풀   3/8  [관전][참가]│  │
│  ├────────────────────────────────┤  │
│  │ 토끼네방    풀   1/8      [참가]│  │
│  ├────────────────────────────────┤  │
│  │ (방이 없으면)                   │  │
│  │ "열린 방이 없습니다."            │  │
│  └────────────────────────────────┘  │
│                                      │
│              [ 방 만들기 ]            │  ← 하단 중앙, 눈에 띄게
│                                      │
└──────────────────────────────────────┘
```

변경점 (현재 대비):
- 닉네임 입력란 제거 (인트로로 이동)
- "연습하기" 버튼 제거 (인트로로 이동)
- "다시 연결" 버튼은 연결 상태에 따라 표시 (현재와 동일)
- [← 뒤로] 버튼 추가 → 인트로로 복귀
- 방 만들기 버튼을 하단 중앙으로 이동 (좌측 사이드바 제거)
- 레이아웃: 좌우 분할 → 단일 컬럼 (방 목록이 전체 너비)

### 화면 3: 대기실 (room_builder — 수정)

현재에서 모드 칩이 이미 제거됐다. 추가 조정:

```
┌──────────────────────────────────────┐
│ [← 뒤로]   대기실   [소리] [설정]     │
│ 호랑이방 · 풀 모드 · 3/8              │
├──────────────────────────────────────┤
│                                      │
│    [P1]     [P2]     [P3]     [P4]   │
│   호랑이    쥐       ???      ???     │
│   호스트    대기중   CPU     CPU      │
│                                      │
│    [P5]     [P6]     [P7]     [P8]   │
│    ???      ???      ???      ???     │
│   CPU      CPU      CPU      CPU     │
│                                      │
├──────────────────────────────────────┤
│ [채팅 로그                           ]│
│ [입력: 메시지 보내기...        ] [전송]│
│                                      │
│             [ 게임 시작 ]             │  ← 호스트만 보임
│        "호스트가 시작할 때까지 대기"    │  ← 비호스트
└──────────────────────────────────────┘
```

현재와 큰 차이 없이 유지. 모드 칩 제거로 생긴 공간에 슬롯이 넓어졌다.

### 화면 4: 게임 (변경 없음)

인게임 HUD는 건드리지 않는다.

### 화면 5: 결과 (신규 — 선택사항)

현재는 게임 종료 후 바로 로비로 돌아간다. 최소한의 결과 화면:

```
┌──────────────────────────────────────┐
│                                      │
│           승리! / 패배                │
│                                      │
│       1위: 호랑이 (나)               │
│       2위: 쥐                        │
│       3위: 용                        │
│       ...                            │
│                                      │
│    [로비로]          [다시 하기]       │
│                                      │
└──────────────────────────────────────┘
```

해커톤에서 이건 선택사항. 핵심은 화면 0~3의 흐름이다.

## 구현 방안

### index.html 수정 (최소)
- `#boot-copy`에 태그라인 1줄 추가: `<p style="margin-top:10px;font-size:13px;color:#8a93a3;">강해 보이면 모두의 적이 된다</p>`
- 나머지는 현재 것 유지

### flow_screens.gd 수정
- `_ready()`에서 `show_page(&"lobby")` → `show_page(&"intro")`로 변경
- `_intro` 페이지에 이름 입력 + 2개 버튼 구성
- `_build()` 안에서 `_build_intro()` 추가
- `pop_page()`에서 `&"lobby"` → `show_page(&"intro")`로 뒤로 가기 추가

### lobby_builder.gd 수정
- `_build_side()` 제거 (이름 입력, 방 만들기, 연습 버튼이 여기 있었음)
- 방 만들기 버튼을 방 목록 아래로 이동
- 레이아웃을 단일 컬럼으로 변경
- [← 뒤로] 버튼 추가

### room_builder.gd 수정
- 최소 변경 (이미 모드 칩 제거됨)

### game_root.gd
- `_set_phase(&"lobby")` 대신 `_set_phase(&"intro")`를 초기값으로 (단, hub_launched일 때는 현재처럼 스킵)

## 우선순위

| 순위 | 항목 | 효과 | 난이도 |
|---|---|---|---|
| 1 | 인트로 화면 추가 (flow_screens) | 첫인상 개선, 이중 진입 해소 | 중간 |
| 2 | 로비에서 사이드바 제거 + 단일 컬럼 | 깔끔한 방 목록 | 낮음 |
| 3 | HTML 태그라인 추가 | 로딩 중 세계관 전달 | 매우 낮음 |
| 4 | 결과 화면 | 게임 완결감 | 중간 (선택) |
