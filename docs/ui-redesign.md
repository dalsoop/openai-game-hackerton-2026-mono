# UI 개선 보고서

## 변경 요약

모드가 full 1종으로 단순화된 것에 맞춰, 불필요한 모드 선택 UI를 제거하고 화면 문구를 정리했다.

## 컷오프 (제거/숨김)

| 요소 | 위치 | 조치 |
|---|---|---|
| 모드 선택 칩 행 (5종 → 1종) | room_builder.gd `_build_mode_row` | 빈 hidden Control로 교체. 칩 배열은 빈 채로 유지 (flow_screens의 `_sync_wait_modes` 호환) |
| 방 대기실 "멤버와 게임을 고르세요" | room_builder.gd 헤더 | "멤버를 모으세요"로 변경 (게임 고르기 없음) |
| 방 대기실 "2 / 2 로비 > 방" | room_builder.gd 헤더 | "대기실"로 간소화 |
| 모드명 반복 표시 | flow_screens.gd `_update_wait_mode_label` | 모드명 제거, "방 제목 | 최후의 1인이 승리합니다!" 또는 "오프라인 연습 | ..." |
| 도움말 매직 컬러 | how_to_play_popup.gd | `Color("3D4654")` → `UiTheme.BTN_DARK` |

## 개선

| 요소 | 변경 전 | 변경 후 |
|---|---|---|
| 로비 타이틀 | "1 / 2 로비" | "다굴 — 8인 배틀로얄" |
| 로비 부제 | "방을 만들거나 들어갑니다" | "방을 만들거나 들어가세요" (존칭 통일) |
| 대기실 슬롯 영역 | offset_top 150 (모드 행 아래) | offset_top 96 (모드 행 제거 후 확장) |
| 조작 안내 | 영한 혼용 ("dash button flash", "hop") | 한국어 통일 ("대시", "점프", "궁극기", "아이템") |
| 조작 안내 헤더 | "로비 > 조작" | "조작 안내" |

## 화면별 최종 구성

### 로비
- 헤더: "다굴 — 8인 배틀로얄" + "방을 만들거나 들어가세요" + 연결 상태
- 사이드: 닉네임 입력 + 방 만들기(파란색) + 다시 연결(숨김, 오프라인 시 표시) + 연습하기(초록색)
- 본문: 열린 방 목록 (제목/인원/참가/관전)
- 버튼: 조작, 새로고침, 설정

### 대기실 (방)
- 헤더: "대기실" + "멤버를 모으세요" + 방 정보
- 슬롯: 8인 원형 배치 (동물 초상화/이모지, 닉네임, 상태)
- 중앙: 인원 수 + CPU 자동 참여 안내
- 하단: 채팅 + 게임 시작 버튼 + 팁

### 설정
- 조작 방식 칩 (자동/터치/키보드) + 설명
- 소리 토글
- 닫기 + 로비로 나가기

### 조작 안내
- WASD/마우스 키보드 조작
- 터치 스틱 조작
- 궁극기/아이템 키
- 승리 조건
