# 설계 — 다굴 (Gang Up)

OpenAI 게임 해커톤 파티 엔트리. 관성 레이싱 초안은 폐기.

## 한 줄

강해 보이는 순간 모두의 적이 되고, 임시 동맹과 배신이 매초 바뀌는 난전.

## 불변

- 파티. 로컬은 인간 1 + CPU. 로비에서 방을 열면 허브가 시뮬하고 빈 칸은 CPU.
- 조작감이 제품. 기본값은 빡셈.
- 마지막 생존(코어/영웅 규칙)이 승리.
- 모드 5종은 **한 Godot 앱 로비**에서 고른다. 모드마다 앱을 복제하지 않는다.

## 책임

| 층 | 위치 |
|---|---|
| 클라·로컬 시뮬·입력 | `apps/server-yjh-dev1/project/` (`hub_client.gd` WS). 원본은 `apps/game-pjh-gang-up` (수정하지 않음) |
| 권위 시뮬·방 | `apps/server-yjh-dev1/` |
| 웹 경로·Helm | `apps/server-*/hackertone.yaml` + `deploy/` |

## 조작

WASD 이동, 마우스 조준, 좌클릭 일반 공격, 우클릭 장비 스킬(차지). 둘을 같이 누르면 좌클릭만 유효(연사 버그 금지).

## 아직 약함 (플레이테스트)

사운드·타격 스쿼시·캐릭터 속도 차별. 수치 바꾼 날은 `FEEL-TUNING.md`에 한 줄.
