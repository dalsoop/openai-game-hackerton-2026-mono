## 물리 (기본 철학)

- 가속은 느리고, 미끄러짐은 큼.
- 조향은 속도에 비례해 약해짐(고속에서 핸들 안 먹음).
- 벽 충돌 시 속도 크게 깎임 + 튕김.
- "쉽다"는 피드백이 나오면 기본 friction↓ drift↑.

## 튜닝 워크플로

1. `npm run dev` 로 로컬 서버
2. 햄버거로 슬라이더 조절 → 즉시 반영
3. 좋은 프리셋이면 `docs/FEEL-TUNING.md` 에 수치 스냅샷
4. 출시 빌드는 패널 없이 확정 수치만
